# App 基座与用户模型资产：需求核对

[English](ASSET_CONTROL_AUDIT.en.md) · [完整版本需求](MULTIMODAL_RELEASE_PLAN.md) · [版本摘要](releases/v0.3.0-plan.md) · [实际开发状态](DEVELOPMENT.md)

核对日期：2026-10-28。**当前需求文档符合“App 仅更新基座，模型由用户自行选择、下载、管理”的要求。** 文档符合不表示完整功能已实现或真机已验收。

具体需求复述：

1. **App 是共用基座。** 更新界面、引擎、任务、后台、API 和配方 / 目录元数据；APK 不含模型权重、模型专用词表或音色数据。
2. **模型由用户按需安装。** 用户选择模型 / 量化 / 配方并查看完整依赖后，明确下载或导入；安装、升级、浏览和缺资产任务均不隐式下载，也不要求安装全部支持模型。
3. **模型由用户独立管理。** 在“本地”暂停 / 继续、配置、更新或删除；App 升级保留现有资产与参数，不静默替换权重，删除模型保留基座并保护共享组件。
4. **所有模型平级、标签独立。** 生文 / 生图 / 生视频 / 生音频可多选；引擎 / 管线 / 格式 / 组件 / 后端需求、安装状态和设备验证分别标记。无审查是单独内容标签，不能代替兼容性证据。
5. **保留现有入口和本机执行边界。** 推荐内容、顺序和标记保留；其他 HF 模型从“全部 / 搜索”选择。支持范围表示基座适配能力，不表示任意 HF 权重均可运行；实际生成全部在同一 Android 手机完成。

需求依据已同时出现在 [中文需求](MULTIMODAL_RELEASE_PLAN.md)、[English requirements](MULTIMODAL_RELEASE_PLAN.en.md)、[发版摘要](releases/v0.3.0-plan.md)、[结构化策略](proposals/multimodal-release-scope.json)、[仓库约定](../AGENTS.md)与[发布流程](RELEASING.md)，彼此没有要求终端用户全量下载模型的冲突。

后续按 A11 验收零模型安装 / 升级、浏览无下载、显式选择范围、模型独立更新、升级保留和共享资产删除保护。**结论：需求基线一致；实现和设备验收继续逐项补齐。** 不应把模型目录登记数、下载成功或桌面演示当成手机已支持模型数。
