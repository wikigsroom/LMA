# App 基座与用户模型资产：需求核对

[English](ASSET_CONTROL_AUDIT.en.md) · [完整版本需求](MULTIMODAL_RELEASE_PLAN.md) · [版本摘要](releases/v0.3.0-plan.md) · [实际开发状态](DEVELOPMENT.md)

核对日期：2026-10-28。**当前需求文档符合“App 仅更新基座，模型由用户自行选择、下载、管理”的要求。** 文档符合不表示完整功能已实现或真机已验收。

具体需求复述：

1. **App 是共用基座。** 更新界面、引擎、任务、后台、API 和配方 / 目录元数据；APK 不含模型权重、模型专用词表或音色数据。
2. **模型由用户按需安装。** 用户选择模型 / 量化 / 配方并查看完整依赖后，明确下载或导入；安装、升级、浏览和缺资产任务均不隐式下载，也不要求安装全部支持模型。
3. **模型由用户独立管理。** 在“本地”暂停 / 继续、配置、更新或删除；App 升级保留现有资产与参数，不静默替换权重，删除模型保留基座并保护共享组件。
4. **所有模型平级、标签独立。** 生文 / 生图 / 生视频 / 生音频可多选；引擎 / 管线 / 格式 / 组件 / 后端需求、安装状态和设备验证分别标记。无审查是单独内容标签，不能代替兼容性证据。
5. **保留现有入口和本机执行边界。** 推荐内容、顺序和标记保留；其他 HF 模型从“全部 / 搜索”选择。支持范围表示基座适配能力，不表示任意 HF 权重均可运行；实际生成全部在同一 Android 手机完成。

需求依据已同时出现在 [中文需求](MULTIMODAL_RELEASE_PLAN.md)、[English requirements](MULTIMODAL_RELEASE_PLAN.en.md)、[发版摘要](releases/v0.3.0-plan.md)、[结构化策略](proposals/multimodal-release-scope.json)、[仓库约定](../AGENTS.md)与[发布流程](RELEASING.md)，彼此没有要求终端用户全量下载模型的冲突。

后续按 A11 验收零模型安装 / 升级、浏览无下载、显式选择范围、模型独立更新、升级保留和共享资产删除保护。**结论：需求基线一致；实现和设备验收继续逐项补齐。** 不应把模型目录登记数、下载成功或桌面演示当成手机已支持模型数。

dev.6 新增 Nano 签名 worker 和第八种显式 HF 配方。词表、音色提示 codes 与外置 `.data` 仍为用户资产；临时执行工作区仅建立持有租约的硬链接，不安装或更新模型数据。见 [Nano 说明](MOSS_NANO_ENGINE.md)。

dev.7 的[模型独立更新](MODEL_UPDATES.md)以 62 项主机检查覆盖明确选择、失败保留、过期确认、原子切换和回退；不是 App 触发更新，也不把旧 API ID 指向新权重。A11 的物理设备安装 / 升级证据仍缺失。

dev.8 新增[用户自选文本包](TEXT_ENGINE.md)，与其他模态共用任务和结果；不选择或迁移用户旧权重，不因 App 更新下载文本模型。66 项新增主机文本检查和 147 项 UI 回归通过，均不替代 A11 的手机安装 / 升级证据。

dev.9 的[已有模型迁移](MODEL_MIGRATION.md)通过本地校验 / 硬链接复用资产，保留原 ID、来源和参数，接入原详情的共用任务 / 版本入口；未完成下载明确暂停，用户继续才恢复。69 项主机迁移检查和 156 项 UI 已通过，A11 的物理 Android 升级门槛仍待完成。

dev.10 的[共用执行槽](SCHEDULING.md)将常驻文本、聊天 / API 和任务接入相同进程与取消边界，43 项主机检查验证用户所选资产复用、自动切换和停止意愿保留；不下载模型，不代替完整模型或物理设备验收。

dev.11 的[输入素材](LOCAL_INPUTS.md)由用户明确导入 / 上传，与模型资产独立。新增素材操作不下载、加载或替换任何模型；现有生产配方仍只接受文字。64 项素材、49 项调度及 182 项 UI 检查不替代 A11 物理 Android 验收。

dev.12 的[扩散基座](DIFFUSION_ENGINE.md)仅更新签名运行代码、配方与策略；SDXL 编码器 / VAE、Turbo / LCM 权重和 LoRA 仍需用户选择。十六个模板不触发下载，LCM 本次任务参数不改写基础设置。83 项扩散主机及 194 项 UI 检查均不替代 A11 设备验收。


dev.13 的[Z-Image / FLUX / Qwen / Wan 基座接入](ADVANCED_DIFFUSION.md)增加四种用户自选组件模板、严格组件角色、采样器 / 调度器 / flowShift 原生绑定、Qwen 尺寸与 Wan 帧数约束。174 项扩散主机检查（Java 117 / C++ 57）、425 项基座（配方 / 完整性 233）与 203 项 UI 通过；35 张截图与录屏 / GIF 是显式 UI FIXTURE。组件家族校验不证明具体规模或蒸馏方法；没有模型输出或 Android 实测。App 仅更新基座，二十个模板均不隐式下载；全部目标与设备门槛继续属于同一完整 v0.3.0，无新 Release。

dev.14 接入 [Sana 移动管线 / MNN](MNN_SANA_ENGINE.md)：真实 ARM64 CPU worker、13 个用户自选组件、Qwen3 metadata 白名单、分阶段释放编码器、独立 CFG / token / 线程参数与不可变任务快照。74 项主机 / C++ 检查不包含模型推理；全部 21 个模板仍只登记元数据、由用户确认下载。445 项基座与 208 项界面检查通过；37 张截图及录屏 / GIF 均标识 UI FIXTURE。没有 Android 生图 / 耐久证据，完整 v0.3.0 的冻结目标和发布门槛保持不变，未创建新 Release。
