# 默认接口端口 52187

[English](API_PORT.en.md) · [API 指南](API.md) · [v0.3.13 更新说明](releases/v0.3.13.md)

v0.3.13 / code63 将公开模型接口的默认端口由 8080 改为 **52187**。手机本机客户端使用 `http://127.0.0.1:52187/v1`；开启“服务 → 允许局域网访问”后，同一内网电脑使用 `http://手机IP:52187/v1`。以服务页实际显示的地址为准。所有请求继续使用原有 Bearer API 密钥。

## 安装与升级逻辑

| 编号 | 场景 | 结果 |
| --- | --- | --- |
| 1 | 新安装，没有保存端口 | 使用 52187 |
| 2 | 从旧版本升级，原来使用 8080 | 首次启动迁移至 52187，并保存一次性迁移标记 |
| 3 | 升级前使用其他有效自定义端口 | 保留原端口，包括 1024 与 65535 边界 |
| 4 | 完成迁移后再次手动编辑端口 | 保留主动选择；后续启动不重复覆盖 |
| 5 | 历史保存值超出 1024–65535 | 使用 52187 恢复 |
| 6 | 设置的新端口被占用 | 提示端口不可用；保留可恢复的原监听，不影响独立的内部文本引擎 |

迁移在应用启动、服务创建之前执行。启动、设置保存、内网地址、内部 HTTP 客户端及空模型页面使用相同默认值。用户仍可在设置中填写 1024–65535 的有效端口。内部模型引擎继续使用独立回环端口，不受公开默认端口调整影响。

覆盖安装保留模型文件、逐模型设置、任务历史与 API 密钥，不下载或替换权重。已连接的客户端不会自动知道新地址：请将默认端口为 8080 的连接配置改为 52187。已有其他自定义端口的客户端继续使用其实际端口。

## 请求示例

在手机上使用回环地址；电脑使用开启内网访问后的手机地址。`$lmaKey` 由当前客户端从安全输入或自己的环境变量取得，不写入文档或提交。

```powershell
$lmaBase = 'http://PHONE_IP:52187'
Invoke-RestMethod "$lmaBase/health" -Headers @{ Authorization = "Bearer $lmaKey" }
Invoke-RestMethod "$lmaBase/v1/models" -Headers @{ Authorization = "Bearer $lmaKey" }
```

```python
from openai import OpenAI
client = OpenAI(base_url="http://PHONE_IP:52187/v1", api_key=lma_key)
models = client.models.list()
```
