# 每个模型的参数

[English](MODEL_SETTINGS.en.md) · [使用手册](USER_GUIDE.md) · [文档目录](README.md)

## 入口与保存

进入 **模型库 → 本地 → 已下载模型卡片上的设置图标**。上下文、CPU 线程、思考模式、单次输出上限、温度和系统提示词均随模型 ID 独立保存。内置、HF 下载和设备导入使用同一流程；未完成下载的条目不能编辑推理参数。“设置”页仅保留下载源、HF 令牌、自动加载、开机恢复、服务端口和主题等应用偏好。

数值框支持下拉预设和直接输入，不要求只能选择预设值。例如可以输入上下文 `1536` 或输出 `333`。离开输入框、选择预设和保存时会校验；超过上限自动回填当前最大值，低于下限回填最小值，整数项向下取整。空白或非数值恢复该字段最近的有效值。原生端再次校验；只有收到对应成功确认才显示已保存，失败保留草稿。

## 上限如何确定

| 参数 | 默认 | 约束来源与行为 |
| --- | --- | --- |
| 上下文 | 2048 | 读取该文件 GGUF 的 `general.architecture` 与对应 `[architecture].context_length`；范围为 2 到该值。默认超限时也会调整 |
| 单次输出上限 | 512 | 最大为**所选上下文 − 1**，至少给输入保留一个 token；缩小上下文时一起调整。输入、模板与历史实际占用的 token 可能使可输出量更少 |
| CPU 线程 | 最多 4 | 1 到 Android 报告的可用处理器数；这是设备约束 |
| 温度 | 0.7 | 应用支持 0–2，可直接编辑小数 |
| 思考模式 | off | off / auto / on，传给当前引擎，部分模型可能忽略 |
| 系统提示词 | 内置本地助手提示 | 可编辑或留空，最多 4000 个字符 |

例如 GGUF 声明上下文上限 `8192`，输入 `100000` 后自动变为 `8192`。若自行选择 `1024` 上下文，输出填写 `9999` 会变为 `1023`；这不保证一次实际输出 1023 个 token。

GGUF 通常声明训练上下文，没有通用、独立的“最大输出长度”字段；LMA 因此使用共享上下文约束，不把 HF `generation_config.max_length` 默认值当成硬上限。[GGUF 官方格式说明](https://github.com/ggml-org/ggml/blob/master/docs/gguf.md)解释了架构与上下文字段。

无法读取元数据时，界面明确显示“未读取到模型上限，暂用应用上限 8192 tokens”。这只是保守的应用兜底，**不是已确认的模型上限**。不推算 RoPE 外推能力。声明上限也不代表手机内存足够；加载失败时应降低上下文或选择更小模型。

## 什么时候生效

- 修改当前运行模型的上下文、线程或思考模式，保存后重新加载该模型；应用正在生成回复时先停止生成，再修改这些加载参数。
- 输出上限、温度、系统提示词用于下一次**应用内对话**，不需要重启引擎。
- 编辑另一个模型不会改变正在运行模型的参数。切换模型、异常恢复或开机恢复均读取所选模型的配置。
- 外部 API 客户端自行发送消息、温度与 `max_tokens`。LMA 不把应用内系统提示词或输出上限强制注入外部请求；引擎上下文仍取决于加载模型的配置。

## 存储、升级与实现

`Store` 将 `profiles` 和 `metadata` 写入应用私有的 `models-state.json`，使用 AtomicFile。HF ID 由仓库、固定提交和文件路径组成；不同量化或提交具有不同配置。重新选择同一文件复用其 ID。删除 HF / 手动模型会删除其配置；删除内置权重保留该内置 ID 的设置，方便重新下载。

升级首次迁移旧版全局推理参数到已有模型，并保留已经存在的独立配置；写盘后移除旧全局键。此后新增 HF / 导入模型从独立默认值开始。相同签名覆盖安装保留数据，卸载会删除数据。

`GgufMetadata` 在下载完成、打开参数和加载前读取 GGUF v2/v3 小端元数据；最多处理 64 MiB 头部、100000 个键和有界数组，不分配权重或完整 tokenizer。按文件大小 / 修改时间缓存，文件变化后重新读取并调整已保存值。它不是完整 GGUF 校验器。`ModelSettings` 在原生端归一化约束，`EngineHost` 与 `ChatRunner` 按明确模型 ID 取值。

85 项后端检查包含二进制 GGUF、边界、持久化、迁移及真实子进程参数 / HTTP 请求检查；66 项界面检查包含编辑、预设、超限归位和模型间独立性。没有 Android 真机测试。演示中模型上限由明确的模拟桥接提供，不能作为该具体权重的真实元数据证据。
