# 模型卡片直接删除 · v1.0.2

[English](MODEL_DELETE.en.md) · [使用手册](USER_GUIDE.md) · [版本说明](releases/v1.0.2.md)

## 操作

1. 打开 **模型 → 本地**，找到要管理的模型；也可先按生文、生图、生视频、生音频或生 3D 筛选。
2. 点击模型卡片底部的 **垃圾桶图标＋删除**，无需进入详情页。文字 GGUF、多媒体模型包与 LoRA 使用相同的外层入口。
3. 确认窗口核对模型名称，再点击 **确认删除**。点击 **取消** 或返回键不会提交删除。
4. 下载排队、传输、校验或暂停尚未结束时，入口显示 **暂停后删除**，暂时不可点击。先暂停，待传输停止后再删除；原生服务仍会检查并发状态，避免界面与传输状态竞争。

尚未选择或下载的目录候选不显示本地文件删除按钮。有暂停、失败或其他已保存传输记录的模型可以从卡片进入原有删除流程。详情页原有“删除本地资产”仍可使用。

## 删除范围与保护

文字模型继续使用 `deleteModel`，模型包继续使用 `bundleRemove → 确认 → deleteBundle`。本次更新只调整入口，不改变资产存储或确认合同；运行中、在用任务、共享组件和租约仍遵循现有原生保护。拒绝原因由程序显示，用户停止相应操作后可以重试。模型包默认保留其逐模型配置，重新下载仍由用户决定。

真实手机验证只打开确认窗口并取消，核对升级前后已安装资产和偏好；实际确认删除使用程序夹具，避免拿用户模型做破坏性测试。程序检查不代表模型质量、完整模型推理或长期后台耐久。
