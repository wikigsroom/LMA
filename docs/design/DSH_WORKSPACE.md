# LMA v1.2.0 · 对话工作区设计规范

[English](DSH_WORKSPACE.en.md) · [设计目录](README.md) · [版本说明](../releases/v1.2.0.md)

本规范落实用户 2026-11-06 的最新要求：风格与布局全面向 [Deepseek-Harness-Local-Android](https://github.com/Soodok/Deepseek-Harness-Local-Android) 靠拢。此前 UI10 云母分区的视觉及导航要求由本规范取代。Logo 21、Slogan 04、模型及接口能力继续保留。

## 01 · 参考核对与边界

参考版本固定为 `02e89ea7d9a6d211e38777c6a409f6cdf5dc0888`，不是依据项目名称猜测界面。[来源、文件 SHA256 与决策](workspace-decision.json)记录 README、实际界面图、窄屏侧栏／设置插件、Framer、主题与设置布局的核对范围。DSH Mobile 是 Android 外壳与上游 WebUI 的组合，宣传图配色不能替代真实工作区的灰黑布局。

| 编号 | 参考特征 | LMA 落地 |
| --- | --- | --- |
| U01 | 左图标栏，主区域留给对话 | 五个入口移入侧栏；首页改为对话 |
| U02 | 窄屏展开侧栏占满窗口，对话让位 | 全宽抽屉、背景 inert、焦点循环、Escape／返回收起 |
| U03 | 深灰低对比度表面、细分隔线 | 中性灰黑与白色双主题；取消资源磁贴和模型卡片网格 |
| U04 | 圆角输入框，下方选择模型 | 模型选择、＋、发送集中在输入框；历史／新建保留在顶栏 |
| U05 | 紧凑会话列表与状态 | 最近 24 条会话；完整历史仍可分页；全局运行管理始终可见 |
| U06 | 简洁设置与功能列表 | 模型、任务、API、设置与弹层采用同一组颜色、间距、列表及控件 |

LMA 使用自己的 HTML、CSS、JS 和 Android 桥接实现，没有打包 DSH 代码、Agent、云服务或品牌。生图、生视频、音频、3D 仍走 LMA 原来的本机模型与队列；界面相似不代表复制参考程序的后端功能。

## 02 · 页面骨架

`index.html` 提供语义布局，`workspace.css` 定义当前视觉与布局，`workspace.js` 管理侧栏与会话摘要。保留 `mica.css`／`LMAMica` 名称作为既有基础控件和原生安全区、键盘、字号的兼容层；界面当前方向由 workspace 样式及 [tokens.json](tokens.json) 决定。

手机默认 56 CSS px 左栏，600–1079 px 使用 64 px 左栏；图标有中文无障碍名称。窄屏展开后侧栏占满可用窗口，不挤压对话。1080 px 及以上默认 256 px 展开侧栏，可收为 64 px。Logo、新对话、五个功能入口、会话列表、设备信息依次组织。侧栏内会话独立滚动，设置和页脚不会覆盖会话。

顶栏显示页面及模型状态胶囊；手机简化标题，保留「运行管理」。错误提示占据页面内独立行，不浮盖运行管理、对话或模型操作。内容区独立滚动，弹层继续使用原有焦点隔离。

## 03 · 明暗主题与视觉令牌

| 用途 | 暗色 | 明亮 |
| --- | --- | --- |
| 主画布 | `#141414` | `#FFFFFF` |
| 侧栏／浮层 | `#1C1C1E` | `#F7F7F8` |
| 输入框／选中背景 | `#2A2A2D` | `#EEEEF0` |
| 正文 | `#ECECEE` | `#202024` |
| 次要文字 | `#C1C1C7` | `#53535C` |
| 提示文字 | `#ADADB5` | `#62626C` |
| 分隔线 | `#333338` | `#E2E2E6` |
| 交互边框 | `#85858F` | `#7A7A85` |
| 主操作／焦点 | `#99B9FF` | `#2C5FCA` |

新安装默认暗色；明亮与跟随系统仍可在设置选择，保存后重启继续生效。启动脚本、Android 窗口、状态栏、导航栏和 WebView 使用一致背景，避免先蓝后灰的闪屏。双色主题共享结构，不以暗色专属样式遮盖明亮问题。语义错误／警告／成功／NSFW 标记继续使用独立颜色与文字，不能仅靠颜色区分。

以系统字体呈现中文及正文，代码使用系统等宽字体，不下载网络字体。正文 16 px 基准；辅助信息 12–14 px；页面标题 24 px。实际字体缩放由 Android／浏览器可用空间决定。48 px 最小触控范围、2 px 可见焦点环；控件圆角 10 px、输入框 20–22 px、弹层 20 px。模型和任务为有分隔线的列表，媒体作品保留 12 px 圆角预览框。

颜色的机器来源是 tokens.json，构建器生成 `mica-tokens.css` 及 `mica-design.json`。装饰分隔线与可操作边框分开：细分隔线无需冒充交互轮廓，真实边框与焦点满足相应对比要求。[逐组合对比检查](workspace-validation.json)记录实际计算结果。

## 04 · 对话与创作

空对话在主区域显示 LMA Logo、简短欢迎和两个起始提示。圆角输入框居中，手机空态适度上移，短屏和键盘弹出时取消额外底部留白。已有消息时输入框停在消息区底部。用户消息使用灰色气泡，助手消息使用开放排版；思考、代码、复制、停止、流式更新、历史分页继续可用。

输入框底行依次为「＋」、当前模型／下拉、圆形发送／停止。提示文字位于下一行。模型名称过长可截断，选择器保留完整名称与实际已选模型，不再占据第二条常驻工具栏。

「＋」打开原有可选面板：聊天／自动建议／生图／视频／语音／音频／3D／媒体合成、附件、临时参数、模板与视觉配对。普通聊天不出现常驻多选择器表单。临时参数不覆盖按模型保存的默认值。手动创作不要求先加载语言模型；提交、确认、队列、取消、失败与作品引用继续使用生产程序契约。

最近会话只渲染 24 条摘要，完整历史在历史面板按游标分页。切换会话仍调用原生 `selectSession`，不通过前端假造持久化。大量消息保留 60 条有界窗口；流式 token 只更新目标行。侧栏只在原生状态与导航事件时更新，不添加状态轮询、无限 DOM 观察器或媒体自动解码。

## 05 · 模型、任务、API 与设置

| 页面 | 结构与必须保留的操作 |
| --- | --- |
| 模型库 | 标题、添加、紧凑内存／存储摘要、搜索、推荐／本地／轻量／进阶／全部、任务与能力筛选、平级模型列表 |
| 本地模型 | 外层明确显示删除；加载／卸载、独立设置、下载暂停／继续、版本／依赖管理；忙时解释「暂停后删除」 |
| 任务与作品 | 草稿、恢复与资源状态、任务筛选、队列、失败详情、取消／重试、结果与引用；不隐藏未适配或失败状态 |
| API 服务 | 运行中的模型、卸载、独立 API 开关、地址与鉴权、LAN、广播模型、示例与日志；端口仍为 52187 |
| 设置 | 应用偏好、下载来源、HF 令牌、主题与后台偏好、关于；模型推理参数仍跟随模型，不搬回全局 |

推荐前缀仍为 `m08 → m06 → m01`，多模态推荐与功能／能力／内容标签保留。浏览和切换样式不触发下载、加载、卸载或推理。外层删除必须二次确认。卸载释放内存并保留文件、设置和历史，API 监听独立，后续明确 API 请求仍可重新加载本地模型。

## 06 · 适配、无障碍与性能

- 240–319 px 极窄窗口保留图标导航，减少内容边距；不足 240 px 显示恢复提示。320 px 及以上要求所有主要操作可达且无横向溢出。
- 横屏／短屏保留侧栏和内容独立滚动；缩短空态、取消额外留白，不能靠隐藏操作换取布局通过。
- 130%、150%、200% 字号允许更高控件及行换行，聊天可切为整页滚动，模型名称和错误可读。
- 键盘显示时收起图标导航占位，输入区域使用原有单一安全区所有权；关闭后恢复。抽屉返回／Escape、Tab／Shift+Tab、弹层 inert 和可见焦点需检查。
- 无实时模糊、动画噪声、背景渐变、外部字体或常驻动画。遵循 reduced-motion，隐藏页面释放播放资源。
- 主动查看本版截图；自动布局通过不代表真机触感、Android WebView、TalkBack 或设备帧率验收。
