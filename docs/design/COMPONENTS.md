# 云母分区 · 30 类组件与页面契约

[English](COMPONENTS.en.md) · [设计总规范](MICA_BENTO.md) · [适配与验收](RESPONSIVE.md) · [Tokens](tokens.json)

**状态：v1.0.0 已实施；验收范围见 [本版指南](../MICA_V100.md)。** 所有组件必须在暗色和明亮主题可用；组件合同和实际验证分别记录。C 编号固定，后续实现与验收按编号引用，避免只改首页而遗漏弹层、任务和原生窗口。

## 0. 全体组件共用契约

| 项目 | 必须满足 |
| --- | --- |
| 表面／颜色 | 使用 canvas / surface / raised / inset；正文 text，说明 secondary，非关键元数据 muted。浅深主题通过 token 解析，不建两套业务组件 |
| 尺寸 | 常规操作至少 48 × 48 CSS px，图标 20／24px，控件半径 8，模型卡 10，资源 12，弹层 16px；高度为最小值，不能阻止文字放大 |
| 选中 | primarySoft + onPrimarySoft，并有勾选、边线或显式状态；`aria-selected`／`aria-pressed`／原生选中语义与视觉一致 |
| 焦点 | focus 2px + 2px 外间距；焦点不可被滚动容器／固定栏裁掉。键盘 Tab 顺序跟视觉／内容顺序一致 |
| 按下／悬停 | 按下立即反馈，不缩放整张卡；主按钮使用 primaryPressed。鼠标悬停可增强，但不隐藏唯一入口 |
| 禁用 | 实际阻止触发；以文字解释缺依赖／资源等原因。不得仅变灰仍可点击，或将解释连同控件整体降透明度 |
| 加载 | 保留原操作宽度和可读标签；去重提交；显示真实状态。不让 loading 引发大幅位移 |
| 失败 | 就地显示原因与可行操作，持久错误可回看；danger/dangerSoft 不用于普通内容属性 |
| 无障碍 | 优先 button/input/select 等原生 HTML 语义；名称、值、展开、状态可读。图标按钮有明确名称；装饰 SVG 隐藏于读屏 |
| 文字／宽度 | `min-width:0`、内容换行、逻辑边距；重要操作不能被固定行高吞掉。200% 文字放大时可纵向重排 |
| 双主题 | 所有动态创建、portal、原生窗口和媒体控制一并切换；图片、Logo、用户生成媒体保留原色 |
| 动画 | press 100ms、状态 160ms、弹层 200ms，非必要最长 240ms；减少动画时为 0。读屏不逐 token 播报 |

## C01 · 应用外壳、顶栏与品牌

结构：安全区 → 品牌／页面动作 → 可选运行状态 → 当前页 → 主导航。顶栏最小高 64px，Logo 40px，LMA 字标 20px／700，动作 48px；窄屏 Logo 可 36px。设备说明与完整标语可以移入详情，不能挤掉页面操作。顶栏在短屏改为正常文档流。

暗色使用 surface／text，明亮使用白 surface／深 text；系统栏图标明暗同步。品牌图不反色，不加全局透明度。首次进入、主题切换、旋转均不得闪白、重置当前栏目或启动模型。运行状态的读屏顺序在品牌之后，不抢输入焦点。

## C02 · 页面标题与局部工具栏

页面标题 26px／600–700，说明 14–16px，标题与主操作间距 12–16px，区块之后 16–24px。模型库“添加”是独立具名按钮，不能把整行标题作为隐形点击区。一般只有一个主强调操作，其余为轮廓／普通按钮。

标题可换行，长操作在 320–359px 或大字模式下移到下一行。标题高度不固定；加载和错误不会盖住标题。两种主题共用结构，主操作使用对应 primary/onPrimary。页面切换时更新标题可访问语义，不能每次后台状态刷新都重新播报。

## C03 · 云母面板与分区容器

面板为不透明 surface，内层可用 raised／inset；常规内边距 16px，窄屏 12px，组间 16–24px。模型卡圆角 10px，资源 12px，普通分区不堆叠三层边框和阴影。若整卡不可点击，不显示整卡可点击的按下反馈。

装饰 separator 可以低对比，但输入／选择依赖的边界必须用 controlBorder 或另一个已验证识别线索。选中态增加明确勾选与 primarySoft，不靠面板轻微变色。暗色靠明度递增，明亮靠白卡与灰蓝底；不用实时透明材质。卡片内容增长时自然增高，不按概念图固定高度。

## C04 · 资源 Bento 与运行状态带

资源为内存、存储、本地模型等真实字段；数值用 20–24px、tabular-nums，标签 14px，内边距 12–16px，卡间 8–12px。无数据写“—／读取中／不可用”并可查看原因，不能填入概念图的 8GB／64GB／0。资源数值注明可用／总量及单位，不能将下载大小误作运行内存。

普通手机可 2 列 + 1 个通栏，宽度及文字都允许时才 3 列；<360px 或 150% 大字时 1 列／可展开摘要。顺序固定，不因宽度移动含义。运行带用圆点＋未加载／加载中／运行中／失败文字；停止／详情独立按钮。状态更新不高频轮询重绘整个首页。两种主题的斜向 tint 只作装饰，不覆盖文字底色。

## C05 · 模型卡与本地模型行

阅读顺序为模型名／来源 → 功能与能力 → 体积、格式、量化、运行条件 → 状态与操作。模型名 18px／600，信息 14px，区域间距 8–12px。名称正常模式可显示两行，但必须有“详情”读取完整名称；大字模式去除行数截断。HF 仓库路径在任意合理断点换行，不删除标识后缀。

下载／加载／继续／设置使用实际状态决定，至少 48px；窄屏动作整行下移，不能覆盖名称。点击设置只打开该模型参数，不触发整卡加载。推荐与全部保持同等卡片语义，推荐来源另作说明。暗色卡 surface 配 mint 下载，明亮卡白底配深 mint；功能标签不改推荐顺序或过滤资格。

## C06 · 下载行、进度与恢复

行内显示文件或依赖组名称、真实已下／总量、阶段、暂停／继续及取消。进度轨道可 4–6px，旁边文字 14px；读屏 progressbar 有真实 min/max/value，未知总量不设置虚假百分比。校验与安装阶段使用自己的文字，不复用下载 100% 冒充整体完成。

失败保留原因及有效重试／续传入口；不自动重下完整模型或删除文件。状态和按钮组合在 320px 下允许分两行；关键按钮不塞到不可见侧滑区。暗色和明亮的轨道使用 inset，填充 primary／mint，并有文字；进度变化不将每 1% 都作为强制读屏通知。

## C07 · 栏目分段、功能筛选与内容筛选

三组独立：推荐／本地／轻量／进阶／全部；全部功能／生文／生图／生视频／生音频／生3D；内容属性或来源筛选。每组有可访问名称，选中为 primarySoft + onPrimarySoft＋标识。可换行按钮至少 48px；不能在 320px 强塞五个固定列并缩字号。

首选换行而非横向隐藏；筛选不是浏览器页面 tab 时使用普通按钮＋pressed 语义，不虚设无法键盘操作的 tablist。若使用真正 tablist，必须实现方向键、Home/End 与正确 tabpanel 关系。更改筛选保留搜索输入和滚动合理位置；未下载状态与 NSFW 属性不互相替代。两种主题文字与标记的对比度分别验证。

## C08 · HF／本地搜索与搜索结果

输入高至少 48px，字号 16px，内边距 12px，搜索图标 20px；清除为独立 48px 目标，placeholder 不能代替“搜索模型”的标签。显示当前搜索范围：“本地模型”或“HF 仓库”。必要的格式／排序条件置于搜索之后，窄屏纵排。

区分正在搜索、没有结果、网络失败和离线本地空库；旧结果与新请求有明确关系，迟到响应不能覆盖较新搜索。输入时保留焦点、键盘与光标，不重建整个 input。Enter 搜索、Escape 在有意义时清除／关闭建议；可访问结果数适度播报。两种主题均为 inset + controlBorder，焦点不靠 placeholder 变色。

## C09 · 按钮、图标按钮与动作组

主操作 primary/onPrimary；下载等辅助强调 mint/onMint；普通操作为 surface/text + controlBorder；危险操作使用 danger 文本／dangerSoft 并明确“删除”。常规高至少 48px，水平 padding 16px，图标与字间 8px，圆角 8px。仅图标按钮 48px 命中区，20／24px 图形；具名如“暂停下载 Qwen…”而不是“更多图标”。

默认、焦点、按下、禁用、加载必须齐全；hover 仅增强。mint 操作无独立按下色时使用明暗对应 onMintSoft/mintSoft 轮廓反馈或 2px 内标记，不能全按钮降透明度。动作组允许换行，危险动作远离主确认；触控区不得重叠。

## C10 · 模型可编辑预设框

用于上下文、单次输出、线程、温度等：可见标签 → 48px 输入与下拉触发 → 单位／可用范围／来源 → 字段级反馈。用户能从预设中选值，也能直接输入；两者写入同一模型 ID 下的同一字段。输入数字不偷偷改为全局偏好。

键盘可输入、上下选建议、Enter 选中、Escape 关闭；采用已验证的 combobox/listbox 语义或原生可编辑实现，不只画一个假下拉箭头。输入暂态可为空；失焦／保存时解析并按模型元数据、共享上下文／输出预算、设备／应用约束归位。超过上限展示归位值和具体来源；未知模型上限写未知，不能伪称 8192 是模型上限。无效、负值、非有限数按现有规则处理并说明，不保存 NaN。弹出列表在键盘上方可滚动；320px 下字段和说明纵排。暗色用 inset 深底，明亮用浅 inset；选项 focus 与 selected 分开。

## C11 · 表单字段、单位与校验

标签 14–16px 可见；输入 16px、高至少 48px；字段间 16px，相关两字段间 12px。单位位于可访问标签／说明，不只当右侧图标。帮助文字持续可见；错误在字段下方，以 danger + 文字／图标表示，设置 invalid 与 describedby。

提交时聚焦第一个无效字段并将其滚到可见区，但不能每次按键抢焦点。必填、缺依赖、范围约束应提前说明；不知道的能力不可静默默认。两列字段只在每个字段仍至少 240px 且长标签可换行时启用；大字／键盘时退回单列。暗明主题都保留输入轮廓、选择／光标可见性与浏览器自动填充可读性。

## C12 · 开关、复选与单选

标签与控件共同形成至少 48px 高命中行，开关图形可 44 × 24px，复选／单选图形约 20px。开关选中 primary、滑块 onPrimary；未选 inset + controlBorder；同一标签“开／关”或状态文本可读，不仅左右颜色。原生 input 优先，Space 可切换。

开关用于立即生效的偏好；多选依赖用 checkbox，互斥后端／主题用 radio／select，不能互相混用。禁用原因靠近标签。长说明占下一行，大字不裁成一条固定高列表。LAN 开关和自动启动说明明确真实影响，不出现“允许远程推理”误导。主题切换不重置控件值。

## C13 · 模型选择器与列表选择

触发器高至少 48px，显示当前模型名、任务能力、已下载／未就绪等必要信息；弹层项高至少 56px，名称可多行。使用完整 ID 防同名混淆；选中有勾号与语义。只按真实能力禁用并显示原因，不把目录可见等同可运行。

支持搜索、键盘定位和返回当前项；打开弹层焦点进入有意义位置，关闭返回原按钮。手机全宽底部面板／对话框，宽屏为居中对话框，不做屏幕边缘很小的悬浮列表。暗明都用 surface，选项选中 primarySoft；当前运行模型与仅选中模型的标记不能混为一谈。

## C14 · 五入口导航

顺序固定为模型库、对话、任务、服务、设置。底栏最小高 64px + 底部安全区，图标 24px，文字 12–14px；每项至少 48px 命中，均有标签。选中使用 primarySoft 标记＋onPrimarySoft 及 aria-current，不仅换一抹颜色。

可用宽度 ≥840px 且避开折叠遮挡时可转 80px 侧轨，同入口同状态；不是依据设备品牌切换。大字可用多行标签／侧轨纵向滚动；极窄窗口允许导航多行增高。键盘遮挡时见适配规则，不能在被键盘盖住的底栏保留可聚焦按钮。两种主题底栏不使用透明模糊来透出内容。

## C15 · 对话框、底部面板与确认

包含标题、内容滚动区、明确关闭／取消与主操作。圆角 16px，padding 16–24px；手机左右至少留 12px，宽屏宽 480–640px，具体不得超可用区。高内容允许滚动，不能把标题、固定按钮和键盘叠成不可操作区域；短屏确认按钮可回到同一滚动流。

使用 dialog／正确模态语义，打开管理焦点、隔离背景，关闭恢复发起处；Back／Escape 仅关闭当前层，不丢已保存任务。点击遮罩不直接执行破坏性动作。深色遮罩 64%、明亮 40%，主体 surface 不透明；表单键盘弹出可见当前字段与确认。原则上一次一个主模态，不套三层弹框。

## C16 · Toast、横幅与字段反馈

短反馈 toast 最小 padding 12px、文字 14–16px，可换行，靠近底部但避开导航／IME；成功用文字，可配小图标。一般自动消失约 3–5s，不承载唯一重试／删除撤销操作。需要用户决策的错误留在字段、任务卡或横幅中直到处理。

横幅含原因、下一步和可选关闭，关闭按钮 48px；长原因占多行。dangerSoft／warningSoft／infoSoft 配对应文字，不用鲜红整屏。读屏普通反馈 polite，严重阻断按需 alert，避免同一错误同时多处重复强播。主题切换后已显示反馈也更新。

## C17 · 空、加载、离线与不可用状态

空状态以 24px 图标、20px 小标题、16px 说明和一个直接动作组成，不用大插画挤走工作流。“未下载模型”“当前筛选无结果”“网络失败”“不支持此基座”分别说明。无模型时不出现忙碌动画或假进度。

骨架只在实际请求等待时短暂显示，尊重减少动画，且不清空已经有用的本地列表。重试、清筛选、去全部、导入等动作必须已存在。暗明都用 raised/inset 的静态占位，不用难以识别的低透明度文本；窄屏文字和动作自然换行。

## C18 · 对话消息与流式内容

正文 16px／1.5，消息组间 16–24px，内容最大宽 760px，窄屏占满可用宽度；用户与助手通过角色文字／位置／边线区分，不能只靠气泡颜色。模型名、时间和取消／复制等动作不覆盖正文。代码、图片、原任务卡按各自组件插入，未知块保留可读回退与原身份。

streaming 更新当前文本节点，保留用户选择、滚动与输入焦点；用户上滑后不强制回底，提供“新内容”入口。错误／取消显示真实状态并保留已有内容；读屏按合理段落或结束播报，禁止逐 token 打断。长公式／代码在内部滚动，不拖宽消息。明暗主题语法颜色分别核对，不用一套暗色高亮配浅底。

## C19 · 输入区、附件与手动模式

模型／模式选择 → 已选附件及角色 → 多行输入 → 发送／取消。输入最小 48px，自动增高到约可见区域的三分之一后内部滚动；发送为独立至少 48px，窄屏可移至输入下方。文字保留草稿；中文输入法组合事件期间不误发 Enter。

手机回车默认换行，发送按钮始终可见；物理键盘快捷键有说明并兼容组合输入。手动生图／视频／音频／3D 不要求先加载语言模型。附件显示图像／音频等角色、合法性、移除及来源，不静默转为另一种输入。IME 出现时输入区随可用高度调整，不被固定底栏盖住。两种主题 inset 输入＋清晰边界，光标／选区可见；不得因主题切换清草稿。

## C20 · 原始任务卡与队列

结构为原任务 ID／模型 → 真实阶段和状态 → 参数／素材摘要 → 进度／耗时 → 可用动作。队列、加载、执行、收尾、成功、失败、取消分别显示；未知百分比写阶段，不随机增长到 99%。耗时是事实，不能当作生成时间上限或自动终止倒计时。

取消按钮至少 48px，明确“请求取消／已取消”，重复取消去重；重试需保留原任务关系，失败可展开原因，不能批量清空错误伪装成功。窄屏操作下移，长 ID 可复制；选中只控制查看，不重启任务。暗明使用相同状态文字和 soft 配色，NSFW 不着失败色。历史、恢复、共享队列及后台任务身份必须保留。

## C21 · 图片、视频、音频与 3D 结果预览

结果提供类型、名称、尺寸／时长／格式、保存／分享／详情及来源；预览宽不超容器，图片保留比例，透明底可见；全屏图片有返回。视频和音频手动播放，有可访问播放／暂停、进度／音量；列表不能同时自动播放。3D 预览按需创建，在显式交互区旋转／缩放，不劫持整页垂直滚动。

媒体懒加载；离页暂停解码／释放非活动 GPU 视图。3D 失败有文件／元数据回退，不把加载缩略图称作完整模型成功。两种主题不反相原始媒体；播放器控制和 checkerboard／错误占位分别适配。视频真实时长显示到适当精度，不能用循环播放假充 >5 秒。

## C22 · 素材选择、引用与来源

素材行／卡显示缩略、类型、原始文件名、来源任务、可用性和选择状态；48px 选择区，勾选有语义。来源关系在详情可展开，长文件名换行，全名可读／复制。依赖素材删除先显示引用影响，遵循现有租约／引用保护；不因卡片从视图消失而删除文件。

选择器可按任务所需角色筛选；不兼容项显示原因而非任意隐藏。空库可导入，不自动创建或下载样例。暗明同一 metadata 结构，选择用 primarySoft；缩略图非必要时不批量解码。手机为单列，宽屏在最小卡宽允许时多列，大字退回单列。

## C23 · 顺序模板与步骤列表

W01–W06 使用纵向编号步骤、输入／输出摘要、依赖状态和执行按钮；连接线只是次级装饰，不是可拖拽节点。步骤标题 18px，说明 14–16px，操作 48px；参数表单采用 C10／C11。当前、待运行、完成、失败、跳过有文字，不以线条颜色猜测。

手机步骤单列；宽屏最多“步骤列表＋当前详情”双区，顺序和模型平级不变。缺依赖、源素材不可用和取消保留真实步骤状态。模板选择不下载权重，不新增 ComfyUI 插件、无限画布或图导入。两种主题均用不透明面板；非运行模板不持续动画。

## C24 · 本地 API 服务、广播模型列表与密钥

服务区先显示停止／运行、选中本地模型和启停，再显示 `http://127.0.0.1:52187/v1` 的实际当前地址、LAN 开关和可发布本地模型。地址和端口来自配置，不能以示例覆盖自定义端口。已下载且配置有效但尚未加载的广播模型，与当前运行模型分开标注；能力标签不承诺公共 API 未实现的输入。

密钥默认遮盖，显示／隐藏／复制分别为 48px 动作；截图和日志不得泄露明文密钥。URL、代码和日志在自己容器横向滚动／复制，普通说明换行。LAN 描述为允许同网客户端调用手机，不是云推理。两种主题都保持地址、状态、输入和系统权限提示可读；运行时换主题不启停服务。

## C25 · 设置、关于与主题选择

设置按外观、下载／HF、服务／后台、关于分组；每行最小 56px，高度随长说明增长。暗色／明亮／跟随系统是清晰互斥选择，保存后即时反映当前有效主题；新装暗色不覆盖既有选择。HF token 同密钥保护，不进入示例截图。

上下文和输出不作为统一全局设置；此页提供“前往本地模型设置”入口。关于使用正式 Logo 21、标语 04、实际版本／许可等，无外网字体依赖。手机单列，宽屏可两列设置分组，但不按行交错阅读顺序。原生授权、电池设置跳转后返回保留当前位置。

## C26 · 菜单、详情提示与长按

菜单项至少高 48px，图标与文字间 12px，危险项写“删除”并与常用操作分隔。菜单宽度不超过可用区，方向自动避开右边缘、IME 和折叠遮挡。按钮有展开状态，键盘／Back／Escape 可退出，关闭返回触发处。

tooltip 不能承载唯一名称、错误或操作。触屏提供点击详情／持久文字，长按可作增强而不是唯一使用方式；悬停和键盘 focus 都能获得同类说明。暗明菜单为 surface＋必要边界，不能透明到看不清下面与上面的字。200% 文字下菜单可增宽／增高滚动，不截掉选项。

## C27 · 表格、代码、JSON 与日志

普通信息优先键值列表；真正需要二维比较时才使用表格。行最小 48px（含操作），表头清晰，单元格正文可换行；屏幕不足时表格本身可横向滚动，页面主体不跟随。代码保留原字符和复制，单独 inset 容器，字号建议 14px，可缩放，不把 API 示例截图化。

日志有界显示、按需展开并有清理视图／复制等现有动作；自动滚动尊重用户上滑。异常栈和大 JSON 不默认无限展开，不输出凭证。暗明语法颜色和选区均可读；不要用过滤敏感日志为由删掉可诊断的错误阶段。表格标题和滚动区域具备可访问名称。

## C28 · 能力、运行基座、内容与证据标签

固定四个语义维度：功能（生文／生图／生视频／生音频／生3D；图像／音频／视频输入等）、基座／依赖、内容（无审查／Abliterated／NSFW 等）、证据（作者声明／元数据提示／适配／已测范围）。安装／运行状态另列。标签文字 14px、padding 4 × 8px、圆角 6px；可点标签仍需 48px 命中区，不能把静态标签错误做成按钮。

功能可使用 primary／mint／info 等 soft 色，必须写清文字且无高低等级；内容使用 contentSoft/content，不能借 danger 表示。未知或未核对明确显示，普通模型不加无依据标签；“多模态”必须展开具体输入／输出与原生／适配边界。窄屏换行，关键兼容性不藏到“+N”；次要标签可展开但有全量可读入口。

## C29 · HF 文件、依赖包、导入与下载确认

显示完整仓库／文件／格式／量化／大小、角色和所需依赖，明确支持／未知／不兼容原因。用户主动选择下载对象与必要依赖；多文件 bundle 用层级列表而非无序勾选所有文件。确认区给总下载量（已知时）和本地空间提示，不把下载资格等同模型可运行。

导入使用 Android 可访问文件选择，返回后保持上下文；离线本地导入不触发 HF 请求。长路径换行／复制；文件列表可搜索／滚动，确认动作始终可达。两种主题包括原生文件选择／授权界面尽可能协调；无法控制的系统界面不谎称完全换肤。校验／续传仍用 C06，错误保留阶段。

## C30 · 生图、生视频、生音频、生 3D 参数面板

表单由所选模型／配方 schema 决定：提示词、种子、尺寸、步数、音色／语言、时长、参考输入、LoRA 等只在真实支持时出现。按“必要输入 → 常用参数 → 可展开进阶”组织，不做所有模型共用的空白大表单。限制来源可读；未知能力不以按钮外观冒充支持。

视频目标必须 >5 秒；若模型／后端不能满足则给真实限制，不伪造帧、重复片段或更改文件 metadata 交差。生成不设壁钟超时；显式取消、资源失败和错误仍须处理，连接超时不得把已接纳任务误标取消。音频角色、3D 几何／纹理与图像参考要区分，失败后保留已有输入供调整。手机单列，≥600px 且字段宽足够才局部双列；大字／键盘退单列。两种主题全面复用 C10／C11／C20，不增加远程执行选项。
