# v0.3.13 实现与验证

[English](IMPLEMENTATION_V0313.en.md) · [端口逻辑](API_PORT.md) · [发布说明](releases/v0.3.13.md)

本版改动集中在公开 API 默认端口与一次性偏好迁移。共用 `ApiPort` 定义 52187 和迁移规则；应用先迁移偏好，随后服务启动、设置保存、地址广播和内部 HTTP 请求读取相同默认值。生产页面的无状态回退、初始 HTML 地址和开发界面夹具同步更新。

| 编号 | 本版检查 | 结果与范围 |
| --- | --- | --- |
| 1 | 新装／旧默认／自定义端口／一次性迁移／无效历史值 | 后端新增 5 组断言，含 1024、65535 边界 |
| 2 | 生产界面回环与内网地址 | 新增 2 项，完整 796 项界面检查通过 |
| 3 | 程序及构建证据 | 62 套／15,122 断言，75 份当前程序／构建记录 |
| 4 | APK 与静态检查 | ARM64／Android 9+，原签名，41 个原生库，16 KiB 对齐，lint 0 错误；既有警告仍披露 |
| 5 | 真机程序与空闲性能 | 24 项程序检查及 8 项性能检查，保留已有模型，无模型推理计入程序门禁 |
| 6 | 真机内网请求 | 另见本版补充证据：原签名升级、旧端口关闭、用户配置保留、实际 PNG／WAV 和媒体协议 |
| 7 | 文档与页面媒体 | 中英 README／连接指南、十组开发界面、真机 5 页截图及录屏／GIF |

本轮受影响的后端、社区、下载暂停、文档输入、API 与广播、工作台、恢复、文本、迁移、调度、准备、组装、图像、MNN、HF、配方建议、音色、Sana 与 LTX 程序检查均重新执行；未变动的原生组件证据按当前源码指纹核验，不重新运行完整训练模型。

真机为 motorola edge plus／Android 12／API31，不能作为 Z20 或 X30 的专项验收。新端口的模型结果另列于[内网报告](../verification/supplemental/v0.3.13/lan-http.json)，不混入零模型程序检查计数。旧视频仅在新端口复测传输，原始测评保留于 [v0.3.12](DEVICE_BENCHMARK_V0312.md)。

62 配方、82 模型包、18 扩展引擎和既有生文、14 个推荐及原有文本顺序完整保留。APK 只更新基座。3D 有效产物、全部模型手机画质和长期后台耐久仍按发布说明列为未验收；源码适配不替代这些验收。
