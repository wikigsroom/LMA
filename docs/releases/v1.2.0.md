## 使用逻辑 / Operation

打开即进入对话。点击左侧图标切换模型库、任务与作品、API 服务、设置；点击侧栏折叠按钮查看最近会话，手机展开后对话区暂时让位。输入框底部选择模型，「＋」打开本次创作或附件，具体参数继续跟随模型保存。顶部「运行管理」可卸载模型，模型库「本地」提供删除、下载管理与独立设置。

Open directly to chat. Use the left navigation for Models, Tasks/artifacts, API and Settings; expand it for recent conversations. A narrow expanded sidebar occupies the centre. Select a model in the composer and use Plus for creation or attachments. Local retains per-model defaults and file management; top Runtime management exposes Unload.
