## 使用 / Use

进入「模型 → 全部 → 生图」选择 Sana-Sprint，检查 14 组件、约 6.29 GiB 资产与 Gemma 独立条款后主动点击下载，也可逐组件导入。「本地」管理传输和独立设置；完整安装后点击使用，填写正面提示词并提交。超限参数归位，不接收负面提示词、图片或 LoRA。任务内临时改动不覆盖模型设置。App 安装、升级和浏览不会取得或替换模型。

Open Models → All → Image, review the fourteen components, about 6.29 GiB and separate Gemma terms, then explicitly download or import. Local manages transfers and saved model settings. After installation, choose Use, enter a positive prompt and submit. Bounds clamp; negatives/images/LoRAs are unsupported in this named profile. Temporary task changes leave stored model settings intact. Installing/upgrading/browsing never acquires or replaces weights.
