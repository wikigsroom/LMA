# LMA v0.3.12 / code62 — 正式 Release / Stable release

Android 本地多模态模型接口与无固定执行时限基座。下载完整且配置有效的模型自动进入服务模型列表；生文、生图、生视频、语音、音乐、生 3D 平级。用户继续选择、下载与管理模型，APK 只更新基座。This stable release adds a local multimodal API and removes fixed generation deadlines. Models remain user-controlled; no weights are included or downloaded automatically.

## 使用逻辑 / Usage

1. “模型库 → 推荐 / 全部 / HF 搜索”选择所需模型，主动下载完整组件；在“本地”编辑该模型参数。Preserves all14 recommendations, the original text prefix, NSFW labels,62 recipes,82 bundles and18 extension engines plus text.
2. “服务”启动接口；“接口可用模型”自动列出已完整安装、配置有效的模型，即使尚未加载。Start Service, then discover eligible peers with `GET /v1/models` and inspect their task/schema/readiness metadata.
3. 真实 OpenAI SDK 可调用图片 `n=1 + PNG + b64_json` 与语音 `response_format=wav`。视频、音乐、图生3D、多视图等使用 `/v1/lma/jobs`，按模型声明上传 typed roles，轮询／事件查看结果，下载真实产物。No fake GPT aliases or arbitrary HF-format compatibility claim.
4. 相同幂等键／正文复用原任务，参数只首次冻结；终态墓碑至少24小时。慢同步请求最多等待120秒，504携带任务ID，后台继续；取消用 `POST /v1/lma/jobs/{id}/cancel`。Explicit retry uses a new key; deletion of history is separate from cancellation.

## 主要实现 / Changes

- 稳定实例／目录修订、原子发布缓存、ETag／HEAD、逐模型能力与设置；不在空闲发现请求中扫描／加载权重。A cached catalogue excludes partial assets, invalid configurations and standalone dependencies; output/task/dependency/content tags remain independent.
- 原子幂等意向和任务墓碑；上传、产物 Range／If-Range、事件、图片输入无虚构文本提示，文本按请求显式加载。Unsupported modes fail before enqueue instead of silently dropping fields.
- Sub2API 可选原生 Go 源码扩展，固定官方 v0.2.19 / `dece26153621959ccd7635814f4b2d08304e681a`；保留原分组鉴权／白名单，持久绑定手机实例与调用者，私有注册表不覆写数据库，缓存事件后按用户过滤。No production deployment or database/billing changes; no cross-phone retries or cloud inference.
- 移除原队列两小时、文本加载五分钟与文本生成读取的固定执行时限。保留主动取消、真实内存／系统资源保护和模型输出约束。HTTP waits/connection guards remain separate and do not terminate admitted async jobs.
- 原生3D工作器识别空稀疏结构、内存分配失败和权重模型族不匹配，保存退出／诊断信息；真实失败不伪装为GLB成功，不静默更换模型或参数。

## 验证 / Validation

常规程序 **62组／15,115项断言**与75份程序／构建记录通过。最终 APK 的真机程序检查 **24项**、已安装模型空闲性能 **8项**、真实 OpenAI SDK／原生 Go 网关→手机联调 **28项**通过。空闲状态主线程最大间隔27ms，无超过100ms的停顿。API发布专测34项；原生Go合同加固定上游路由测试12项。常规程序计数与真实模型推理分开，详见附件 `validation.json` 与版本证据。

Device: **motorola edge plus**, Android12/API31, SM8250, approximately11.4GiB RAM; these results do not establish X30/Z20 or general Android performance. Five existing models/settings and the original signer are preserved. No new model downloads/copies, ROOT, emulator, Docker, WSL or off-device inference.

SDK产生真实WAV与PNG；最终APK的Wan CPU视频已按真实49帧／8fps输出 **6.125秒** MP4（200,149字节，732.170秒计算及轮询总耗时），手机元数据与FFprobe一致，不靠重复片段、插帧或慢放。画面为模糊色块，画质未通过。最终包TRELLIS.2一步诊断在886.846秒失败，明确报告`empty_structure`，无GLB；17项接口检查通过。成功3D输出仍未验收。3D、候选包历史结果、耗时、温度、资源范围与失败诊断见[完整测评](../DEVICE_BENCHMARK_V0312.md) / [English](../DEVICE_BENCHMARK_V0312.en.md)。Model quality is not accepted merely because a file is produced;3D has no accepted GLB result unless explicitly shown in the report. Text/music have no installed assets for physical inference; all82 bundles and sustained screen-off endurance are not accepted.
