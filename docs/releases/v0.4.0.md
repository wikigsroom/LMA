# LMA v0.4.0 · 对话与本地创作 / Conversations and local creation

2026-11-03 · 正式版本 / Stable release · Android arm64 · versionCode 64

本版一次接入 20261102 方案的 D01–D12：用户在同一会话选择文字、图片、视频、语音、音乐、3D 或本地合成，生成卡直接关联原任务和素材。模型仍由用户选择、下载和管理；APK 不携带权重，不隐式下载，不使用远程推理。推荐、全部 HF 和本地栏目继续保留。

This release implements D01–D12 of the 20261102 plan together. One conversation hosts text, image, video, speech, music, 3D and phone-local composition; cards refer to original jobs and managed artifacts. Models remain explicit user choices/downloads. No weights, implicit downloads or remote inference are added.

## 使用 / Use

1. 选择“推荐 / 全部 / 本地”中的模型，明确下载并完成配置 / Choose, explicitly download and configure a model.
2. 进入对话，选择创作类型与本地模型；需要输入素材时选定其角色 / Choose a conversation mode/model and assign required artifact roles.
3. 直接提交，或在自动模式先检查工具草稿并确认；任务卡同步原队列 / Submit directly, or review/approve a tool draft; cards follow the original queue.
4. 用“顺序模板”复用成功步骤；合成时明确选择画面与声音 / Reuse successful template steps; explicitly select visual/audio composition inputs.

## 验证与边界 / Verification and limits

本轮以程序验证交付，无可用 ADB 手机；未进行新版真机推理、视觉输出、Android 编解码输出、性能对比或锁屏耐久验收。SQLite 用真实 SQLite 执行升级/失败回滚；PCM 用实际采样数据；UI 为明确标记的桌面桥接夹具。原生资源已编译、签名和包检查；这些结果不等于模型质量或真机输出。

This is a program-validated release. No ADB phone was available: this APK has no fresh phone inference, visual/codec output, latency comparison or screen-off endurance measurement. Real SQLite migration/rollback and actual PCM samples are tested; UI media uses labelled desktop bridge fixtures. Native compile/signature/package checks do not prove model quality or device output.

- m15 的固定 projector 来源已核对；m03/m09/m16 尚缺可核验配对预设，需审核后手动导入清单 / m15 has pinned projector provenance; the other three still require reviewed pairing metadata.
- App 视觉桥与公开 API 不等价；OpenAI chat 保持文本子集，原图片 PNG/语音 WAV 合同保留，视频/音乐/3D/合成/任务链走 LMA 异步接口 / The App visual path is distinct from public text-only OpenAI chat; LMA async endpoints serve the remaining media/chain operations.
- 保留 62 配方、82 包、18 扩展引擎加文本及 14 推荐；不代表任意 HF 模型可执行 / Frozen coverage is retained, without claiming arbitrary HF execution.
- 历史 3D empty_structure、视频质量不足、OOM 等记录不改写；没有新的质量验收结论 / Historical failures remain intact; no new quality acceptance is claimed.
- 端口仍为 52187，生成无固定耗时上限；生成视频必须真实 >5 秒，不能靠循环或降速伪造 / Port 52187 remains; no generation wall-clock deadline or fake repeated/slowed motion video.

安装与升级 / Install and upgrade: use `LMA-0.4.0-arm64-v8a.apk` with the original signing identity. Back up important user data before user-initiated uninstall; normal in-place upgrade keeps local models/settings/chat data. Release attachments contain SHA256 checksums, source and separate evidence/media archives. Earlier Releases and their original physical evidence remain unchanged.
