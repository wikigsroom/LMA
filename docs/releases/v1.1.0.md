# LMA v1.1.0 · DSH 工具协议与模型卸载 / Function tools and Unload

正式版本 / **Stable Release**, versionCode **68**, Android ARM64 / API28+。保留原签名、默认端口52187、Logo21、Slogan04和云母分区明暗主题。旧标签及附件原样保留。

v1.0.2 在接口校验层拒绝 DSH 的标准工具字段，导致请求尚未送到模型就返回400。本版接通函数声明、模型原生工具选择、调用方执行、结果回传及下一轮推理，并明确展示模型内存卸载入口。

v1.0.2 rejected DSH's tool fields before native inference. This release implements the full function-tool round trip and clear resident-model unloading, preserving client tools and agent functionality.

## 安装和使用 / Install and operate

1. 从正式Release下载 `LMA-1.1.0-arm64-v8a.apk`，用SHA256SUMS核对后覆盖安装。Original signing preserves installed models, settings and history.
2. 服务页启动API；同手机客户端地址 `http://127.0.0.1:52187/v1`，输入自己的LMA密钥和已安装模型ID。Keep DSH function tools enabled.
3. 不用模型时点击顶部**运行管理 → 卸载模型**，核对名称并确认。Downloads remain; stop the API separately to prevent subsequent client-driven reloads.
4. 生成任务与文本共用执行槽；队满429可退避重试。Streamed late failures arrive as error events, never a fabricated DONE.
