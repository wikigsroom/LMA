Startup reconciles indexed committed outputs only when the complete immutable request and same-phone origin match. Recovered tasks stay interrupted. Generator-owned uncommitted files are reclaimed without deleting indexed media or user model assets. History cleanup removes reviewed terminal identities/idempotency keys atomically; active work and later-finished jobs remain. Shared capacity checks reserve no slot and do not start inference or downloads.

Startup validates committed metadata and file size, without rehashing large media. It cannot detect same-size changes or recover an unpublished index transaction. Actual selected input execution retains its full hash check. This is a business-foundation update, not new Android/model acceptance.
