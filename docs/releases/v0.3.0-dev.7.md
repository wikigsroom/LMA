## 行为 / Behavior

- 在本地模型详情选择独立更新目标，先核对组件内容 / 来源 / 路径 / 格式 / 校验与许可、能力、参数差异。用户指定版本关系；不自动寻找更新、下载或替换模型。Select a pinned target from Local and review component/provenance/license/capability/profile changes before an explicit transfer.
- 下载与启用分别确认。完整校验前不能启用，下载成功不切换；源 / 目标配置或版本代次变化使旧确认失效。Downloading and activation require separate consent, with completeness and stale-review guards.
- 迁移时按新 schema 归位，披露移除、默认值、类型 / 枚举 / 文本 / 联合尺寸重置；可选择保留目标配置。旧模型及其参数保留，可明确选择回退，最多记录 64 次切换。Preview settings adjustments or retain the target profile; old files/settings stay available for explicit rollback.
- 一次原子元数据提交修改当前偏好、目标参数和记录；权重与不可变 ID 不移动 / 改写。API 和已提交任务不因偏好标记改变而重定向。Atomically commit preference/profile/history without mutating weights or fixed task/API identities.
- 运行租约保护切换；排队 / 运行任务的主模型与 LoRA 都禁止删除，提交 / 受保护删除共享锁。取消计划暂停该目标传输并保留资产。Protect running leases and queued base/adapter references; cancellation preserves acquired assets.
- App 仍只更新基座，零模型启动 / 浏览 / 升级不触发模型下载；旧记录完整统一仍待完成。HF 广泛发现不等于任意权重兼容。The App ships foundation code only; complete legacy-record unification remains open, and HF discovery is not universal runtime support.
