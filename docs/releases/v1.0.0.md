- No model weights downloaded or complete trained models run for this UI release. Program fixtures, actual phone interactions and historical generated examples remain distinct.

## 安装与附件 / Installation and assets

Install `LMA-1.0.0-arm64-v8a.apk` over an existing original-signed installation and compare it with `SHA256SUMS`. Model downloads remain user-selected. The Release includes the signed APK, exact source archive, verification archive, screenshot archive, real-phone MP4/GIF, labelled program demos, build/validation records and checksums. **prerelease=false**; previous tags and release assets are preserved.
