## 具体用例与调用核查 / Documentation checks

- 中英 C01–C18、A01–A04、H01–H18、P01–P24 编号与覆盖一致；全部本地链接、页面锚点与嵌入媒体路径检查。
- README Python 示例使用语法编译检查，PowerShell 使用解析器检查；示例未对手机发起请求。聊天模型按 loaded＋text 标签选择，SSE 无 [DONE] 时明确失败。
- 24 组／4,438 项为原 v0.3.1 程序证据；仅核对来源指纹，发布核查工具改变后更新工具指纹，不重新运行完整模型。
- 14 项发布后源码核查回归使用临时 Git 仓库；真实已发布源码 ZIP 按原标签的所有路径、字节数、SHA256 和 Git blob 核对。受保护文件与上游原始头仅流式哈希。
- 当前文档／工具更新与不可变附件分别核查，不用重新打包或放宽检查规避过期源码包。不调度虚拟化环境，不启动浏览器，不下载／复制／执行完整模型。

The audit checks bilingual case IDs, paths, anchors and media; parses PowerShell and Python examples without making requests; verifies existing program fingerprints; and exercises 14 temporary-repository regressions. Original source archives are checked against every tagged Git blob and SHA256. Protected assets and upstream headers are hashed without content inspection. No virtualization, browser, complete-model execution or physical device is used.
