2026-10-30，内部开发 APK，`versionCode=30`。本轮继续实现主要业务闭环：用户先检查当前模型 / 输入 / 参数，处理缺失条件，再主动入队、查看结果和继续生成。检查、提交共用生产解析器；未发布完整 v0.3.0 Release。

This checkpoint connects actionable admission checks to the existing generation workbench. It shares production validation with submission, without automatic jobs/downloads/model-default changes. This is an internal development APK, not completion of the frozen model/device scope.
