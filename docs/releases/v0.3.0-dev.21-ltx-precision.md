## 结果边界 / Boundaries

53-token提示词A的最终embedding最大误差仍为2.3752450942993164e-5；局部误差与传播误差分开记录，不把局部算子数量当作验收通过数量。两种候选各三次文本推理后，组合候选A / B embedding最大误差为2.861e-6 /1.192e-6；两种A轨迹探测仍分别为0.00395262 /0.00382924，均高于原0.003门槛；完整修复、性能与全部回归待验收。
