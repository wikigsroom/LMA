# LMA v0.1.2 · Android ARM64 无审查模型工作台

**预发布 / Prerelease · 2026-10-27 · Android 9+ · ARM64 · CPU · versionCode 3**

## 中文

LMA 将模型选择、自行下载、本地对话和 OpenAI 兼容接口放进一个无需 ROOT 的 APK。内置 14 个具有作者 Uncensored / Abliterated 声明的具体 GGUF 版本；使用固定仓库提交、准确大小及发布者 SHA256，构建时检查依据与权重匹配。应用不额外添加关键词审核或模型回复内容过滤，系统提示词可编辑。

- 模型库搜索、筛选、作者依据、串行下载、暂停 / 续传、SHA256、HTTPS 直链和系统文件导入。
- 原生前台服务、独立 llama.cpp ARM64 CPU 进程、对话流式显示、停止生成、SQLite 历史。
- 默认本机 `http://127.0.0.1:8080/v1`；可选局域网，支持带密钥的 `/v1/models`、`/v1/chat/completions` 与 SSE。
- 线程、上下文、输出、温度、思考、端口和提示词设置，浅 / 深色主题，日志导出，可选开机恢复。
- 中英文 README 与完整指南、7 张页面截图、操作视频及 2 份 GIF、可核对的验证记录和后续发布流程。

**开始使用：** 下载下面的 `LMA-0.1.2-arm64-v8a.apk`，安装后打开“模型库”。建议先选约 398 MB 的 Dolphin Qwen 0.5B（`m01`），下载校验后加载；再使用“对话”或“服务”。APK 不含权重。后台使用需要系统通知、电池及厂商后台设置允许。

**验证范围：** 54 后端 + 25 协议 + 5 SQLite + 31 界面，共 115 项桌面断言；Lint 0 错误、7 警告；另有 APK 签名、原生库和对齐检查。**当前无 Android 真机，尚未验证安装、真实 ARM 推理、Z20 速度 / 内存、拒答率或锁屏耐久。** 视频与 GIF 为实际界面加明确模拟原生桥接，不是手机推理实录。普通 Android 应用不能保证永久后台存活，单次生成仍受 EOS、token 上限和取消影响。

## English

LMA combines model selection, downloads, local chat, and OpenAI-compatible serving in one no-ROOT Android APK. Its 14 built-in GGUF variants have publisher Uncensored / Abliterated declarations, pinned revisions, exact sizes, and publisher SHA256. Catalogue builds require matching weight attribution. The app adds no keyword moderation or response-content filter; the system prompt is editable.

- Search/filter, publisher evidence, serial transfers, pause/resume, hash checks, HTTPS links, and Android file imports.
- Native foreground service and separate llama.cpp ARM64 CPU process, streaming chat, cancellation, SQLite history.
- Localhost default `http://127.0.0.1:8080/v1`, optional LAN, authenticated models/chat-completions/SSE.
- Runtime and prompt settings, light/dark themes, log export, optional boot restore.
- Chinese/English READMEs and guides, seven screenshots, MP4/two GIFs, public verification records, and update/release workflow.

**Start:** install the APK below, open the model library, and try the approximately 398 MB `m01` Dolphin Qwen 0.5B first. Download, verify, and load it before using Chat or Server. Weights are not bundled. Background operation needs Android notification/battery and vendor settings.

**Validation:** 115 desktop assertions (54 backend, 25 protocol, 5 SQLite, 31 UI), Lint with 0 errors/7 warnings, and separate signature/native/alignment checks. **No physical Android device was available: installation, real ARM inference, Z20 performance/memory, refusal rates, and screen-off endurance are untested.** Media is the real interface with explicitly simulated native state, not phone inference. Permanent background survival is not guaranteed; EOS, output limits, and cancellation still end requests.
