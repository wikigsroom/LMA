# 2026-11-03 · UI10 云母分区定稿与完整设计规范

[设计系统 / Design system](../design/README.md) · [决策 / Decision](../design/decision.json) · [静态检查 / Static validation](../design/validation.json)

用户选择 **10 号云母分区 / Mica Bento**，并追加完整的明暗差异与宽窄机型适配约束。新增中英设计总规范、30 类组件契约及适配／验收文档，覆盖五个页面、二级弹层、媒体、任务和 API 服务。机器可读 tokens 统一两主题 31 个语义颜色、字号、间距、圆角、状态、断点与约束；CSS 为隔离的文档参考，未接入运行界面。

The user accepted **UI10 Mica Bento** and requested explicit light/dark and varied-width adaptation. Bilingual specifications define the visual system, 30 components and adaptive acceptance across all five pages and overlays. Machine-readable tokens define 31 semantic color roles per theme, typography, geometry, motion and breakpoints. Reference CSS is isolated documentation, not runtime integration.

配套的[明暗颜色与状态对照图 / Theme reference board](../media/design/mica-theme-reference.png)直接按 tokens 绘制，附[来源与哈希](../media/design/mica-theme-reference.json)；不是 App 截图，不作为浅色主题或真机布局通过的证据。

新装默认暗色；合法既有暗色／明亮／系统偏好保留。7 档宽度按真实可用窗口选择，18 组视口目标覆盖窄屏、宽屏、短横屏及折叠／分屏，另含键盘、安全区、130%／150%／200% 文字、TalkBack、焦点和懒加载规则。A01–A20 均为下一步实施验收，未运行的目标明确标 pending。

Dark is the installation default, while existing valid Dark/Light/System choices are preserved. Seven width bands and 18 viewport targets include narrow/wide/short/fold/split cases, with IME, insets, text scaling, TalkBack, focus and lazy-media rules. A01–A20 remain pending implementation and acceptance; static specifications do not count as device passes.
