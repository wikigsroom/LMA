## 中文

LMA 的产品定位改为“本地模型工作台”。**“推荐”完整保留 `m08 → m06 → m01` 的模型、顺序、标签和固定作者依据**；普通 HF 模型通过“全部”及搜索添加，下载不会替换推荐。

- 关键词、`owner/model`、HF 仓库链接搜索，GGUF / HF 全部格式发现，下载量 / 喜欢数 / 更新时间排序，仓库前后分页。
- 仓库提交固定后分页读取文件树，显示 GGUF 文件名、量化、体积及 SHA256；选择后进入原生下载任务。
- 新增“本地”栏目，统一管理内置、HF、手动导入的已下载模型及未完成任务；支持本地搜索、加载、暂停 / 续传和删除，HF 记录去重并持久保存。
- 模型设置迁入“本地”已下载模型：上下文、输出上限、线程、温度、思考和系统提示词独立保存，旧全局参数自动迁移。下拉预设允许手动编辑；依据 GGUF 上下文、共享输出容量和设备 / 应用范围校验，超限自动回填。
- “无审查”保留为专门标签，已核对作者声明与仅元数据识别区分；普通模型不带标签也可添加。
- 设置中可保存 / 清除 HF 令牌。令牌仅发送到官方 HF HTTPS 默认端口，认证请求不走镜像，不转发到 CDN。
- 修复暂停下载状态竞争，保留既有无需 ROOT 的后台服务、聊天、历史及 OpenAI 兼容 API。
- 完整双语说明、12 张截图、MP4、4 份 GIF 和公开验证记录均已同步。

**使用：** 安装 / 升级下面的 APK，进入模型库，保留使用“推荐”，或通过“全部 / 搜索”选择 HF 仓库和 GGUF 量化文件下载；到“本地”设置各模型参数、管理并加载，在“对话 / 服务”使用。受限仓库需先在 HF 接受许可并配置读取令牌。APK 不含模型权重。

**支持范围：** HF 全格式是仓库发现范围，当前运行器提供兼容的单文件 GGUF 文本对话，不直接运行 Safetensors / ONNX / MLX，不支持分片或单独投影器，不自动转换。架构与手机内存仍需实际加载确认；不是所有 HF 模型都能在手机运行，也未实现 LM Studio 的全部功能。

**验证：** 85 后端 + 45 HF 逻辑 + 25 协议 + 5 SQLite + 66 UI，共 **226 项桌面断言**；另有 **5 项实时公开 HF Mirror 元数据检查**。Lint 0 错误 / 7 条已核对警告，APK 签名 / 包内容 / 14 个原生库 / 对齐检查通过。**无可用 Android 真机，安装、ARM 推理、Z20 性能、锁屏耐久未实测；也未使用真实令牌测试私有仓库。** 因此保留预发布。演示为实际界面加明确模拟元数据、下载与脚本文本，全程有 UI DEMO 标识。

## English

LMA is now positioned as a local-model workbench. **Recommended preserves `m08 → m06 → m01`, their order, labels and pinned publisher evidence.** Discover additional HF models through All/search without changing recommendations.

- Keyword, `owner/model` and repository-URL search; GGUF/all-format discovery; download/like/update sorting and repository pagination.
- Commit-pinned file-tree pagination with GGUF quantization, bytes and SHA256; selection creates a native download task.
- A dedicated Local tab manages built-in, HF and imported downloads plus unfinished transfers: offline search, load, pause/resume and delete. HF IDs deduplicate and persist.
- Per-model context, output, threads, temperature, reasoning and system prompts move to Local. Editable preset combos clamp to GGUF/shared-context/device/application bounds; legacy global preferences migrate.
- Separate uncensored tags distinguish checked publisher evidence from unverified metadata hints; ordinary models remain eligible.
- Optional HF-token save/clear; credentials go only to the official default HTTPS endpoint, never mirrors or CDN redirects.
- Fixed a download-cancellation state race; preserved no-ROOT background service, chat/history and OpenAI-compatible serving.
- Refreshed bilingual docs, twelve screenshots, MP4, four GIFs and public evidence.

**Start:** Install/upgrade the APK, choose Recommended or discover a repository/quantization in All/search, configure/manage/load it in Local, then open Chat or Server. Gated repositories need terms accepted on HF and an authorized read token. No weights are bundled.

**Scope:** All-format HF visibility is discovery, not universal phone execution. This runtime serves compatible single-file text GGUF models; Safetensors/ONNX/MLX, shards, standalone projectors and automatic conversion are unsupported. Loading still depends on architecture and RAM. Full LM Studio feature parity is not claimed.

**Validation:** **226 desktop assertions** (85 backend, 45 HF logic, 25 protocol, 5 SQLite, 66 UI), **5 live public HF Mirror metadata checks**, Lint 0 errors/7 reviewed warnings, and separate package/signature/native/alignment checks. **No phone was available: Android installation, ARM inference, Z20 performance and screen-off endurance remain untested. Real-token private access was not tested.** This is a prerelease. Media uses the shipped UI with clearly simulated state and a permanent UI DEMO banner.
