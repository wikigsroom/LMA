## 行为 / Behavior

- 新增第九种 HF 数据模板 `text_gguf_cpu_v1`。用户选择一个完整文本 GGUF，单独确认下载 / 导入；不预装模型、不自动迁移旧文件。Add a ninth explicit HF data recipe for a complete user-selected text GGUF; no bundled weights, implicit transfers or legacy file migration.
- 复用锁定的签名 llama server，接入 `LocalEngine`、独立参数、任务队列、取消和产物。每任务私有回环端口 / 密钥，固定模型 ID，不跟随推理重定向。Reuse the actual pinned text runtime through shared jobs, with private authenticated loopback and immutable model selection.
- 保存、提交、执行按 GGUF metadata 和设备 / 应用限制回填上下文 / 输出；通用 schema 支持参数依赖，版本确认绑定有效 schema，不兼容记录单独报错。Inspect actual limits, enforce dependent bounds and invalidate stale version reviews without disabling the library.
- 正文 / 思考 / finish reason / usage 保存为经验证的文本 JSON，支持纯文本预览、复制和导出；HTML 作为文本显示。SSE 中断、错误、无 finish / DONE 不记成功。Typed artifacts preserve response/reasoning and completion details; inert preview/copy/export cannot execute model HTML or turn incomplete streams into success.
- App 继续只交付基座；推荐 `m08 → m06 → m01`、既有聊天与 API、用户资产保留。The foundation-only update and user-controlled model boundary remain intact.
