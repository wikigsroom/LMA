# LMA 0.3.0-dev.38 / code42

[中文完整方案](../ZIMAGE_TURBO.md) · [English user flow](../ZIMAGE_TURBO.en.md) · [中文首页](../../README.md) · [English README](../../README.en.md)

本轮将 Z-Image-Turbo 的完整四组件接入现有全部 / HF / 本地模型流程：用户显式选择下载或导入，独立配置八步参数，提交不可变任务并管理生成、取消、恢复和结果。原始 Qwen3-4B、官方完整 VAE 和外置词表保持配套；内容哈希支持复用已有对象，但不自动安装其他模型或自动开始任务。App 继续仅交付基座，推荐 m08→m06→m01、已有资产 / 设置 / 任务保留。

This checkpoint connects complete Z-Image-Turbo assets to existing HF/local selection, explicit downloads/imports, independent eight-step settings, immutable jobs and result management. Original Qwen3-4B and the full official VAE remain matched. Exact object reuse never implies model installation or task execution. Native/production Java host execution, UI fixtures and Android compilation are distinct evidence; complete numerical, quality, resource and phone gates remain pending. This is work within one full v0.3.0 scope, not a reduced Release or a separate work line.
