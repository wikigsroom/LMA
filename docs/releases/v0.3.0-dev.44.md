## 使用与复现 / Use and reproduce

在模型「全部 / 搜索」选择模型，在「本地」管理已有下载与导入。明确选择所需组件并开始下载或从系统文件选择器导入；暂停会取消打开或读取，已完成且完整校验的组件保留。文件提供者可能延迟响应，迟到输入会被关闭；本地未完成组件在重新选择文件后从头导入，不冒充 HTTP 字节续传。关闭基座会暂停未完成工作，重启不自动下载。媒体素材使用同一输入取消逻辑。

Choose a model through All/search and manage it in Local. Explicitly select components before download/import. Pause cancels pending opens or active reads; verified completed components remain. Provider response can be delayed, and late resources are closed. Reselect an incomplete local document to restart that component; this differs from HTTP byte resume. Shutdown pauses unfinished work; restart never automatically downloads models. Media inputs share cancellation ownership.

```powershell
python tools/test_document_input.py
python tools/test_bundle_pause.py
python tools/test_backend.py
python tools/test_foundation.py
# Additional affected program checks are named in verification/program/status.json.
python tools/build.py
python tools/verify_package.py
python tools/test_android_lint.py
node tests/ui-smoke.cjs
python tools/export_development.py
python tools/check_repository.py --development
```

这些命令只做程序、明确夹具、Android 编译和包核对，不要求模型权重；音色元数据程序检查只读取已有本地文件头与校验身份，不进行神经网络执行。本轮没有下载 / 复制完整模型，也没有生成新的模型媒体。复用的[恢复截图 / GIF / MP4](../media/development/recovery/manifest.json)为 dev.42 页面夹具；浏览器在当前回归结束后已关闭。以上均不代表 Android 真机推理、质量、性能或长时间后台实测。

These commands validate programs, explicit fixtures, Android compilation and packaging. The voice-metadata check reads existing local headers/identities without neural execution. No complete model assets were downloaded/copied and no model media was generated. Reused recovery media retains its dev.42 fixture identity. Current UI regression closed its browser. No phone inference, quality/performance or background-endurance claims are made.
