# LMA v0.3.3 · 本地多视图 3D 与诊断 / Local multiview 3D and diagnostics

新增真正的四视图 CPU 推理通道、匹配组件导入、持久运行观察与可主动导出的诊断。App 仍只更新基座；所有模型和辅助资源由用户选择、下载、导入和管理。全部实际生成在同一 Android 手机执行，无需 ROOT。没有加入远程运行方案。

This update adds an actual four-view CPU runtime, matching component imports, persistent observations and explicit diagnostic export. Model assets remain optional user-controlled data. Inference stays entirely on the same Android phone, without ROOT or off-device fallback.

## 验证与安装包 / Validation and package

遵循用户“只做程序验证”的指令：本轮没有完整训练模型下载、复制、推理、ASR、实机或耐久测试；没有 Docker、WSL、VM 或模拟器。真实 Windows 子进程使用有界合成数据，实际相机 / 投影函数单独运行。所有拥有的浏览器页面与上下文在 finally 关闭。

Program-only validation does not accept output quality, full-model numerical parity, phone speed/RAM or screen-off survival. RSS is worker-process peak usage on Android, not model minimum RAM or whole-app memory; Windows tests report it unavailable. Some abrupt terminations cannot send final observations. Existing full-model failures remain historical failures.
