# LMA 0.3.0-dev.36 / code 40

[中文使用与方案](../MNN_SANA_EDIT.md) · [English design/user flow](../MNN_SANA_EDIT.en.md) · [中文首页](../../README.md) · [English README](../../README.en.md)

本轮将 Sana Edit 的图片转换能力接通到共用业务：用户选择完整 15 组件、自行下载或导入、选择本地图片、独立配置、提交不可变任务、实际取消/恢复、保存结果及来源、重启读取与删除素材。并修复共用上传接口对超限请求偶发丢失错误响应的问题。App 仍只更新基座，不附任何模型或自动下载。**此前 dev.35 将该模型归为通用文生图不准确；本轮依据官方配套应用更正，不以图片编辑替代冻结 04 文生图。**

This checkpoint closes the fixed-style image-edit business flow and a shared upload error-delivery bug. Source/host checks, UI fixtures and Android compilation are distinct. The original Sana text-to-image target, independent numerics, image quality and physical-phone acceptance remain pending. This is an internal development checkpoint, not a complete v0.3.0 Release or a new work line.

21 suites / 2,873 checks: 2,741 shared controls, 52 real native edit checks and 80 production Java/native checks. UI: 459 checks. Android Lint: zero errors, 17 existing warnings. Four native images and two managed Java images are real trained outputs. Same-host entry consistency does not establish independent numerics, Android execution or quality.
