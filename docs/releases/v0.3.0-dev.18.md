# 0.3.0-dev.18 — 内部开发检查点 / Internal development checkpoint

公开 Release 仍为 v0.2.0。本次是同一完整 v0.3.0 范围内的内部检查点，不创建新标签 / Release，也不缩减 F-01–F-12、既有生文、01–14 / 16 / 17 或冻结子目标。The public Release stays v0.2.0; this checkpoint does not split, defer or reduce the complete next-version scope.

## 行为与方案 / Behavior and design

现有 `openmoss_native` ARM64 CPU worker 扩展为六条配方，本次新增 TTS / v1.5 / TTSD / VoiceGenerator。官方 config / processor / modeling / README 固定 revision 与哈希已[记录](../../catalogue/evidence/openmoss-delay-publishers.json)，未下载权重或执行远程 Python。32 路 / 8B 与 16 路 / 8B、16 路 / 1.7B 分开校验。两个 TTS 版本几何相同，不能以几何冒充权重身份验证。The existing worker now dispatches six recipes, with four added delay layouts backed by pinned publisher metadata/source review; identical geometry cannot authenticate v1/v1.5 checkpoint provenance.

主干和 extras 仍由用户明确选择；内含 BPE / codec 用依赖标签披露，App 不附带或自动下载模型。TTSD 文本使用 `[S1]`/`[S2]`，参考按角色成对映射，数组顺序不换声；VoiceGenerator 必填声音描述且无参考入口。四者输出 24 kHz 单声道 WAV，参考限 1–10 秒、≤1 MiB、PCM16 / finite float32。原有 Local-v1.5 / SoundEffect-v2 保留独立格式与采样率。Models remain flat peers with audio/capability tags independent of engine/pipeline/format/backend/dependencies. User choice controls every asset transfer and model update.

声音描述、语言、生成预算等随模型保存；本次任务参数固定为独立快照。数值超限归位，非法描述或角色在本机报错。真实生成网格含全部参考及续接前缀，prefill 前严格检查输入/上下文预算，超过就拒绝，不静默缩短生成；固定源码只在生成副本中插入保护，构建回执及许可来源记录声明修改与哈希。Per-model settings and immutable task overrides reuse the common foundation. The actual generation-grid guard runs before prefill; the pristine upstream source remains unchanged, with the generated modification hashed and disclosed.
