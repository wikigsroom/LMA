# LMA v0.3.7 · 真机启动修复 / Physical startup fix

**0.3.7 / code57** 修复了真实 Android 零模型安装后模型目录空白、设备内存不显示的问题。一个尚未准备资产的旧 LTX 条目在读取表单元数据时触发执行校验，导致整个状态快照中断。现在每个条目记录自己的不可用原因，其余模型与设备状态正常显示；任务执行前的匹配资产校验仍严格执行。

## 安装与使用

1. 下载 `LMA-0.3.7-arm64-v8a.apk` 并核对 SHA256；适用 ARM64 / Android 9+。原签名安装升级，保留已有应用数据。
2. APK 只更新基座，不附权重、tokenizer 或音色，不自动下载模型。
3. “推荐”保留 `m08 → m06 → m01`；其他 HF 模型在“全部”或搜索中发现，模型由用户明确下载或导入。“本地”管理文件与逐模型参数。
4. 已有模型选择、任务队列、结果、聊天和本地 API 逻辑保留。HF 可发现不等于任意架构都可在手机执行。

## English

LMA **0.3.7 / code57** fixes a real Android zero-model startup failure. An unprepared legacy LTX catalogue entry previously aborted the complete UI/device snapshot while resolving input metadata. Errors are now isolated per entry; the catalogue and physical memory render, while execution continues to reject missing or mismatched assets.

The patch also fixes instrumentation resource-table compression and media export under a Chinese workspace path. It passes **19 physical program checks** on the device actually reporting **motorola edge plus / Android 12 / SM8250**, including catalogue/UI navigation, Android SQLite recovery, native executable permissions, foreground-service commands, no-model API startup, 401/403 rejection and 409 missing-weight rejection without downloads. With instrumentation detached, seven authenticated health probes and the foreground service survive approximately **60 seconds with the screen off**. This establishes no trained-model inference or endurance result.

The existing **62 recipes / 82 bundles / 18 extension engines plus text**, frozen F01–F12 and selections 01–14/16/17, speech subtargets, both LoRA families, community entries and P01–P06 adapters are preserved. All computation remains on the same phone; users explicitly choose model assets. Recommended remains `m08 → m06 → m01`.

Current evidence includes **59 host suites / 14,939 assertions**, **748 production-page checks**, verified original signing, 41 ARM64 libraries and zero Lint errors (16 existing warnings). Unchanged checks are reused only with exact matching source fingerprints. The APK SHA256 is listed above; source/asset identities are supplied with the release.

Separate actual-phone screenshots, MP4 and GIF accompany the nine labelled desktop fixture flows. Historical failures, C01–C48 scenarios, H01–H18 cases and published v0.3.6 files are retained. No complete trained-model downloads, copies, runs, quality acceptance, tokens/s, peak inference memory or long screen-off inference were performed. DISO's bundled CPU code is **CC BY-NC 4.0**; see the third-party terms.
