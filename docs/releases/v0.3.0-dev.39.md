# 0.3.0-dev.39 · 本地视频业务 / Local video business

本轮把 Wan 2.1 T2V 1.3B Q4 接入用户明确选择四组件、下载 / 导入、独立设置、不可变视频任务、实际 Vulkan 生成、取消恢复和 MP4 结果管理。App 只更新基座；推荐 m08→m06→m01、用户资产 / 旧配方 / 设置 / 任务保留。

This checkpoint adds a complete optional Wan asset profile and the actual CPU text/VAE + Vulkan diffusion route through shared model management, independent settings, jobs and artifacts. Production Android encodes on the same phone; the Windows FFmpeg test port remains separate evidence. It is work inside one complete v0.3.0, with all frozen model, numerical, quality, resource and phone gates retained.
