# LMA 0.3.0-dev.37 / code 41

[中文使用与方案](../FLUX2_KLEIN.md) · [English design/user flow](../FLUX2_KLEIN.en.md) · [中文首页](../../README.md) · [English README](../../README.en.md)

本轮接通 FLUX.2-klein 4B distilled 的完整四组件方案：用户从全部 / HF 搜索选择、显式下载或导入，在本地管理、设置参数并提交生成任务。完成后保存图片和来源；支持真实采样取消、再次执行、重启读取以及删除模型后保留结果。修复共用 Qwen 分词读取器将 HF 文件头当作词项、以及组合字符未规范化的问题。App 仍只更新基座，不附模型或自动下载。推荐 m08→m06→m01 保留。

This checkpoint closes the complete four-component FLUX.2-klein 4B distilled flow and corrects HF Qwen merge-header handling and Unicode normalization. Users explicitly select/download/import models, edit independent settings, submit immutable jobs, cancel/recover and manage results. The App remains foundation-only. Native Windows execution, UI fixtures and Android compilation are reported separately; full numerical, quality and physical-phone acceptance remain pending. This is a checkpoint within the single full v0.3.0 scope, not a formal Release or a separate work line.
