# LMA v0.3.0 · 本地多模态基座 / Local multimodal foundation

完整冻结范围的程序集成版本；GitHub 标为 prerelease，表示手机与模型质量尚无本版实测。全部程序功能同版交付，不拆为缩减功能预览。Complete frozen program scope in one release; the prerelease label preserves the unverified phone/quality boundary.

## 使用与方案 / Use and architecture

App 只交付基座。模型、LoRA、编码器、VAE、音频 codec、分词和音色资源由用户明确选择、下载、导入、更新与删除，安装 / 升级不自动取模型。所有生成阶段在同一部 Android 手机上执行，不需要 ROOT、Termux、外部计算端或 ComfyUI。Models are optional user assets; there is no off-device inference or downloaded executable plugin system.

推荐保留 **m08 → m06 → m01**。“全部 / 搜索”发现 HF 所有格式；“本地”统一管理资产与逐模型参数。HF discovery is broader than executable recipe support. Every model is a peer with output/task and foundation-dependency tags; Uncensored/Abliterated is a separate attributed label.
