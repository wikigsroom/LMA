## Limits / 边界

The template/protocol implementation, model instruction following, Android tool permissions and plugin platform requirements are separate conclusions. Keep previous failed/cancelled observations under their exact APK identities. No external script creates the acceptance file or installs the plugin and then claims DSH success.

The 1B model initially confuses success descriptions with execution and needs explicit stepwise format cues in the accepted file task. No claim of arbitrary model quality, universal HF architecture execution, complete Android application-control permissions or long-running endurance. Previous releases, source/APK bytes, failures and assets remain immutable.

Plugin acceptance covers the actual DSH web pet after engine reload. Android system-overlay bridging, wallet/payment and voice features are not tested by this install. 模板／协议、实际工具执行、网页插件加载和系统权限分别验收。
