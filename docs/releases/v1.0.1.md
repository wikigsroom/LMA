# LMA v1.0.1 · 原对话页面复原 / Restored chat

**正式补丁版 / Stable patch — Android 9+ / ARM64, versionCode 66.**

上一版把两个选择框、五个动作按钮和说明永久放在输入区，挤占聊天空间；顶部模型名与实际状态还可能不一致。本版恢复原来的“顶部模型／历史／新建—消息—紧凑输入／发送”。现有创作功能从“＋”按需打开；保持云母明暗主题、Logo21、原签名及用户模型与历史。

The previous composer permanently exposed two selectors and five actions, consuming conversation space, while its header and initial mode could be stale. This patch restores the original toolbar, message stream and compact composer. Existing creation controls open through “+”; accepted themes, branding, signing and user data remain.
