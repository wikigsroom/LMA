## 验证 / Validation

- **60 组 / 15,032 项程序断言，73 份门禁记录；785 项完整生产 UI 检查。** Production classes, bounded/random fixtures and real child-process protocols; no complete trained-model results counted in this gate.
- **23 项真机程序检查 + 10 项故障专项**，分别计数。熄屏 60.29 秒 / 7 次认证健康请求；保留 5 个已安装模型。Four-byte link probe, 17 component receipts/sizes, native info/device queries, no-queue unsupported-GPU preflight.
- **41 个 ARM64 原生库，16 KiB 对齐，原签名，Lint 0 错误 / 16 原有警告。** APK contains no model data; downloads remain explicitly user selected.
- **57 PNG / 10 GIF / 10 MP4** 当前桌面生产页面，标注 UI FIXTURE；浏览器已关闭。真实 Android 录像保留 v0.3.9 原身份；本轮私人任务和素材不公开。
- 8 项历史性能保留检查；v0.3.9 延迟数据不作为本版新测量。Eight preservation checks are not a new latency benchmark.

**验证偏差 / Declared deviation:** 误选旧 Nano 主机完整模型检查，使用已有资产启动 3 个主机子进程、形成 2 份输出记录；不计入程序门禁或手机通过。旧 Qwen 工具在运行模型前因旧证据指纹退出。Correct bounded program runners were run separately. No complete model was rerun on the phone. [完整记录 / record](../../verification/releases/v0.3.10/validation-deviation.json).
