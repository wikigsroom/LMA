# LMA v1.0.2 · 模型卡片直接删除 / Delete directly from model cards

**正式补丁版 / Stable patch — Android 9+ / ARM64, versionCode 67.**

此前文字模型卡片有垃圾桶，多媒体模型却要进入详情才能删除。本版把生图、生视频、生音频、生3D和LoRA的删除入口放到模型卡片底部，并统一显示“垃圾桶＋删除”。从“模型 → 本地”即可操作。

Previously text cards exposed a trash icon while media deletion was buried in details. Image, video, audio, 3D and LoRA cards now expose the labelled trash/delete action directly. Open **Models → Local**, choose **删除**, review the model name and confirm or cancel.
