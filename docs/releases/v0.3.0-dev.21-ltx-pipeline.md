## 当前执行范围 / Execution boundaries

当前开发 profile 为 256×256、33 帧、24 fps 的两组真实提示词和一次重复；共享相同显式初始 / 解码噪声。RNG 有独立固定定义，不承诺 PyTorch 同 seed 位模式。主机 MP4 为 FFmpeg/libx264，未来 App 仍须在同一手机用已有 MediaCodec / MediaMuxer。

独立参考只比较相同量化 / 转换精度的权重，不证明原始未量化 T5 或 PixArt 权重相同。非平坦、随时间变化和提示词差异统计仅为结构诊断，不是语义准确、运动连贯或画质达标。Windows 子进程观测不是手机 RAM、GPU 显存或整机峰值。

No models are fetched automatically. Developer-exported DiT/ONNX assets are not yet a public one-click App candidate or an on-phone converter. User acquisition, integrity checks and model lifecycle must integrate with the shared foundation before production support can be claimed. The APK continues to deliver only foundation code.

## 本轮实测与未通过项 / Actual results and failed gates

2026-10-29：三次真实任务耗时分别为1410.89 /574.40 /398.16秒，不含整套预先SHA和独立参考。完整验证163项：157通过、6项浮点门槛失败；两个RGB对照最大字节误差均为1，均值分别0.00607022 /0.00381639，在原RGB门槛内。latent最大误差0.00830925 /0.00499147、解码浮点最大误差0.00375907 /0.00617547超过原0.003门槛；两个NCTHW latent对应项同样失败，合计六项。

The test writes complete evidence and retains exit1. Execution=true is separate from numerical acceptance=false. A same-reference-caption Vulkan diagnostic reduces A latent maximum error to0.00172329, suggesting amplification of small T5 differences is a major contributor; it does not close complete-chain, quality or phone gates. The unchanged original thresholds remain required work. Public validation replays this round's three captured jobs/two original references, explicitly disclosing reuse.
