## 行为 / Behavior

- 常驻文本加载、应用内聊天、同步文本 API 和异步生成任务复用一个可取消 FIFO 执行槽。任务等待当前回复，回收旧进程后切换引擎。Share scheduling and wait for active replies before switching engines.
- 队列空闲时只恢复用户仍希望运行的已选文本模型；停止、更换或取消旧代次不复活模型。等待期间可发送或取消一条交互式文本请求。Restore only a still-wanted selection, with generation-specific cancellation.
- 关闭 API 监听取消连接和等待文本；独立任务继续。停止整个服务明确中断任务，模型、参数和结果保留。Keep API, text and task stop ownership independent.
- 提交时检查总容量，取得槽、回收旧引擎后检查实际可用内存、温度和空间。进程仍存活时保留执行槽、模型租约和临时文件，等待真实退出。Recheck actual resources and retain ownership until child exit.
- App 只提供基座和目录 / 配方元数据，模型资产仍由用户选择、下载和管理；没有新增模型数据或隐式下载。Foundation-only updates and explicit asset control remain mandatory.
