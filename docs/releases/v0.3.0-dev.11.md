# 0.3.0-dev.11 · 本地输入素材 / Local input media

日期 / Date: 2026-10-28。**内部开发检查点，未创建 Release。Internal checkpoint, unpublished.** 当前公开版本仍为 v0.2.0。

用户现在可显式导入图片 / WAV / MP4 素材，并与生成结果分别筛选、预览、导出和管理。API 提供四个有界上传会话，按 256 KiB 分块持久提交偏移、显式续传和完整 hash / 媒体校验。任务保存不可变输入回执；排队 / 活动读取保护删除，实际子进程退出后释放。缺失 / 损坏素材本机失败，不下载或替换模型。

Users explicitly import media independently of models. Authenticated bounded uploads persist chunk offsets and validate full hashes/actual media before publication. Jobs freeze receipts, protect queued/execution references and release leases after actual child exit. No URL fetching, implicit model downloads or off-device execution is added.

签名引擎控制输入角色，当前生产配方仍只接受文字。输入表单是契约夹具，不是语音克隆 / 图像编辑 / 图生视频已支持证据。Signed engines control roles; current production recipes remain prompt-only. The input form is an explicit UI contract without claimed model capability.
