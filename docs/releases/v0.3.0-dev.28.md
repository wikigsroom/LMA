The LCM preparation program is now registered in the App. A user explicitly selects a source, prepares a source-bound component, associates it with the runtime entry, then chooses the remaining base and vocabulary. Only a complete verified installation can submit generation. The APK contains code; all learned data remains user controlled.

Fixed training guidance 8.5 is distinct from sampler CFG 1. This condition does not accept additional LoRA that could alter its folded time embedding. The ordinary SD1.5/SDXL LoRA routes remain independent. Java/native validation fails on malformed or mismatched condition files, and native loading errors cannot silently continue with the original bias.
