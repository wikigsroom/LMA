内部开发检查点，**未创建新 Release**。This is an internal checkpoint within the same complete v0.3.0, not a reduced delivery or public Release.

[中文指南](../OPENMOSS_ENGINE.md) · [English guide](../OPENMOSS_ENGINE.en.md) · [实际状态](../DEVELOPMENT.md) · [完整范围](../MULTIMODAL_RELEASE_PLAN.md)

本轮增加真实 ARM64 CPU openmoss worker 和生产 Java 适配器，分别运行 Local-Transformer-v1.5 语音管线与 SoundEffect-v2.0 音效管线。App 只更新引擎、配方与界面；两个匹配的主干 / extras GGUF、内含 BPE 和 codec 均由用户自主选择下载 / 导入。全部 25 个模板只是元数据，浏览、安装或升级不会自动下载模型，推荐顺序不变。

The new worker links the pinned community openmoss native core and its exact llama.cpp submodule, excluding upstream CLI, HTTP server and WAV I/O. All generation stages use the same phone's CPU. Local optionally encodes a user-selected 48 kHz stereo WAV; SoundEffect supports negative conditioning and reports actual solver progress. CFG=1 with a supplied negative prompt fails explicitly instead of silently ignoring it. No full model or Android inference has been performed.
