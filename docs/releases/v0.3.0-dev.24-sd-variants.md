1024×1024 / 4 步 LCM 的 SDXL 原生尺寸样例能辨认狐狸、蓝色带壶嘴茶壶和木质背景；边缘涂抹、画面条纹与其他提示词细节仍需复核。A better native-size sample does not waive the observed low-step problems or complete quality/phone gates.

App 只更新基座，用户决定选择 / 下载 / 导入 / 暂停恢复 / 更新回退 / 删除哪些模型。全部模型平级，功能、依赖、架构和后端标签独立；推荐保持 m08 → m06 → m01。五份新清单只含元数据，不向 APK 或 Git 添加训练权重。All product tokenization, encoders, sampling, VAE and output remain on the same Android phone, without ROOT or external inference fallback.

Java 取消位于生产生成阶段入口；直接原生取消位于实际采样第 1 步之后。Windows 子进程终止、主机内存观察与 Android 协作取消 / Z20 内存 / 锁屏续跑分别记录，不互相替代。GIF / MP4 是标明范围的真实 PNG 静态轮播，非 App 或手机录屏；已有 68 张 UI 夹具保持原范围。本轮未使用 Docker / WSL / 虚拟机 / 模拟器，没有创建浏览器标签页。

The Windows functional metadata port omits metadata fsync; it checks atomic replacement and ordinary restart retention, not Android AtomicFile or power-loss durability. Production model-file sync and complete-file verification still execute.
