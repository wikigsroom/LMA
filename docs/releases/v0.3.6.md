### 使用与升级

1. 下载 Release 中的 `LMA-0.3.6-arm64-v8a.apk` 并核对 SHA256；Android 9+ / ARM64，使用原签名升级以保留已有模型与设置。
2. 模型页“推荐”保持原顺序；“全部”或 HF 搜索发现其他模型，“本地”管理已选资产。HF 可发现不等于任意架构已具备本机运行器。
3. 选择可用配方，人工确认对应文件或导入匹配的本地导出。大型新增 3D / 视觉配方的完整公开下载包尚未核实；提供严格离线导出和本地导入，不提供占位下载链接。原始 PyTorch 权重不能直接当作 Android 包。
4. 在具体模型设置中编辑上下文、输出、步数和资源等参数；超过声明上限自动归位。辅助模型同样有自己的设置，不使用全局推理参数。
5. 工作台选输入，按需显式选择抠图 / 部件识别 / 材质模型，默认均为“无”。缺失或已删除的辅助模型在预检中阻止提交，可在设置中重新选择；不会自动下载或偷偷替换。
6. 前台通知支持离开界面后的活跃任务及 API 服务；系统强停、厂商省电或内存压力仍可结束进程。按系统提示允许通知和后台活动，不承诺未经真机测试的持续时长。

### Usage and upgrades

1. Install the original-signed ARM64 Android 9+ APK after checking its SHA256. Keep the same signer to preserve existing models/settings through upgrades.
2. Recommended retains its exact order. Use All/HF search to discover repositories and Local to manage assets. Discovery is broader than executable runtime support.
3. Explicitly select files for a supported recipe or import a matched local export. Complete public export endpoints for the large new 3D/vision recipes remain unverified: strict offline converters and local import are supplied, without fabricated download packages. Raw PyTorch weights are not Android runtime bundles.
4. Edit each model's own context/output/steps/resource settings. Values clamp to declared limits. Helper models retain their own configurations.
5. Select inputs in the workbench and optionally select foreground/part/material models. Every helper defaults to None. Deleted/missing helpers block preflight and can be reselected; no implicit download or replacement occurs.
6. Visible foreground ownership supports active work and the local API after leaving the UI. Allow Android notifications/background activity as needed. Force-stop, vendor power management and memory pressure can terminate work; unmeasured endurance is not promised.
