# LMA v0.3.8 · 多模态推荐 / Recommendations for every modality

## 使用 / Use

1. 安装 `LMA-0.3.8-arm64-v8a.apk`，需要 ARM64 / Android 9+。原签名升级保留应用数据、已选模型和设置。
2. 打开“模型 → 推荐”，点击生图 / 生视频 / 生音频 / 生 3D，分别显示 3 / 2 / 3 / 3 个模型包。卡片保留功能、运行基座与内容标签。
3. 查看详情与必需组件，再明确点击下载；浏览、筛选和升级不会下载。模型不预装，推荐不等于已安装。
4. “本地”管理所选下载和逐模型参数。选择“使用”后进入对应功能表单，提供本机参考输入，检查匹配资产及资源后提交到共用任务队列。
5. 其他模型仍可通过“全部”与 HF 搜索发现；不是所有 HF 架构都可执行。计算、解码、编码和媒体处理仍在同一手机。

视频包约 4.74 / 6.76 GB，需 Vulkan 和较大内存；推荐 3D 包约 2.63 / 4.20 / 6.62 GB，属于 CPU 长任务。下载量不同于运行内存。Kokoro 本条目使用已适配的英文 profile。推荐项不代表手机性能或生成质量已验。

## English

LMA **0.3.8 / code58** adds eleven optional multimodal recommendations to the unchanged three-model text prefix. Recommended now exposes three image, two video, three audio and three 3D choices with task counts, reasons, resource hints and independent sourced NSFW labels. They reuse existing model identities, details, explicit downloads and Local management. All 82 registered bundles and HF discovery remain available. Installation and upgrades never fetch weights.

Program validation passes **59 suites / 14,973 assertions, including 782 UI checks**. The real phone passes **23 program checks**, including four recommendation categories; a detached ordinary foreground service survives a 60-second display-off API health check. No complete trained weights are downloaded, copied or run. Model quality, speed, peak RAM and sustained screen-off inference remain unmeasured. Video requires Vulkan and substantial resources; 3D choices are long CPU tasks, not verified device performance recommendations.

The original upgrade signer, fully local execution, all frozen foundation/selection/MOSS/LoRA/community/P01–P06 implementations, per-model settings and user-controlled assets remain. Thirty-four assets include current source/evidence, ten labelled desktop recording sets and separate actual-phone recordings. Prior releases are immutable.
