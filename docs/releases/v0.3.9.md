# LMA v0.3.9 · 空闲界面卡顿修复 / Idle UI performance fix

正式 Release，ARM64 / Android 9+，code59，沿用原签名升级。**Stable release, not a prerelease.**

v0.3.8 即使没有加载模型，仍在 Android 主线程重建全部 82 包描述、重复解析参数并编码近 1 MB 状态，阻塞点击与滚动。前端还会重复生成视图、修改计数及刷新隐藏页面。之前的防抖和卡片签名去重未覆盖这些耗时；本版补上实际手机量测。

LMA-authored code is MIT; bundled DISO CPU code remains CC BY-NC 4.0 (noncommercial), and other components/models retain their own terms. Historical releases and evidence remain immutable. No model weights, private credentials or signing keys are shipped.

The stable patch moves expensive catalogue serialization off Android's main thread and reuses validated immutable metadata. Same-phone diagnostics show a roughly 94% reduction in warm snapshot work and remove the measured multi-second main-thread block. The original functional checks lacked a latency measurement; this release adds a version-bound comparison. Current source/evidence, ten labelled desktop recording sets and separate actual-phone media accompany the signed APK. No complete trained weights were downloaded or run.
