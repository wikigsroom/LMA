# dev.21 源码后续：原生旧 LTX 资产准备 / Native asset preparation

2026-10-29 · 未发布 / Unreleased · 现有 APK 保持 0.3.0-dev.21 / code 25

[中文方案](../LTX098_PREPARE.md) / [English guide](../LTX098_PREPARE.en.md) / [完整同版需求](../MULTIMODAL_RELEASE_PLAN.md)

本轮把旧版 DiT 的资产格式准备实现为可在 Android 原生编译的流式组件，避免生产方案依赖开发机 Python。App 的用户入口与生产 adapter 尚待接入，不能把独立组件当作已交付 App 功能。This source/host checkpoint is not a new APK or complete Release.
