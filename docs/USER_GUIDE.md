## 安装与首次运行

需要 ARM64 Android 9 或更高版本。APK 不适用于 32 位系统和 x86 设备。手机型号、系统版本及内存还会影响具体模型；没有完成本项目真机验收。

从项目 Release 下载 APK 并核对 SHA256。允许当前安装来源，完成安装后直接打开 LMA；没有额外终端、ROOT、账号或云端密钥步骤。Android 13+ 如提示通知权限，允许后更便于查看前台工作并停止服务。

首次建议下载 `m01`（Dolphin Qwen 0.5B，约 398 MB），观察下载、校验、加载和一次完整回复，再尝试较大模型。模型文件之外还需运行内存、数据库及 Android 安装空间。

## 模型库：选择、下载、加载

推荐页保持 `m08 → m06 → m01` 的原有顺序、标签和作者依据。轻量 / 进阶保留原精选分组。“全部”连接 HF，可搜索关键词、`owner/model` 或仓库链接，按下载量、喜欢数或更新时间排序；默认 GGUF，也可选“HF 全部格式”。进入仓库后选择量化文件再下载，仓库与文件列表均支持前后分页。

“本地”统一管理已下载的内置、HF 和手动导入模型，也显示进行中或中断的下载。这里的搜索只过滤本地条目，不联网。可打开模型设置、加载、暂停 / 续传和删除；删除运行中的模型须先停止。除“本地”外，在搜索框输入会切到 HF 搜索；点击推荐等栏目会清空搜索并回到对应列表。详见 [HF 与本地模型](HF_MODELS.md)。

点击本地或精选模型名称可查看格式、文件名及哈希；有已核对无审查声明的条目还显示处理方式及作者入口。在线仓库名称 / 标签提示的结果单独标为“无审查 · 元数据”，未核对作者声明，普通模型不带此标签。

1. 点击“下载”，任务串行执行，卡片显示速度和进度。
2. “暂停”保留部分文件；“继续”按服务器的 Range 能力恢复。服务器返回完整文件时会从头重写。
3. 下载满进度后进入校验，只有通过完整性及已知发布者哈希检查才成为已下载模型。
4. 点击“加载”启动引擎，顶部先显示加载中，再显示就绪。加载会同时提供 API。
5. 初次完成自动加载默认开启，但只在此前未选择模型时生效；可在设置中关闭。
6. 切换模型会结束旧引擎再加载新模型。删除当前运行模型之前先停止服务；删除同时清理下载记录、部分文件和拒收文件。

“添加模型”提供 HF 发现、HTTPS GGUF 直链（可填 SHA256）及系统文件选择器导入。手动文件不会获得已核对无审查标签；请自行确认来源、许可、架构和内存要求。无发布者预期哈希时，格式、长度和本地哈希不能替代来源认证。

HF 所有格式可发现，并不代表都可在手机上加载。当前只下载兼容的单文件 GGUF 文本模型候选；分片、视觉投影器及不适用任务有禁用原因。Safetensors / ONNX / MLX 等可查看来源，未实现转换或对应运行器。

公开 HF 模型无需令牌。受限 / 私有仓库需先在 HF 接受许可，再在“设置 → Hugging Face 访问”保存具备读取权限的令牌；也可清除。令牌只保存于应用私有设置，页面仅显示设置状态，认证请求只访问官方源，镜像和 CDN 不接收令牌。本轮没有真实令牌仓库验收。

自动源依次尝试 Hugging Face、HF Mirror；也可固定源。自定义其他域名不会改写为镜像。最大单文件为 12 GiB，预留空间为 64 MiB。导入被中断后需从头复制，不支持导入流断点续传。

## 对话：发送、停止与历史

就绪后进入“对话”。当前模型显示在顶部，可选择已下载模型。输入消息发送；有思考内容的模型可展开思考区域。代码复制只复制代码正文。

点击停止会取消当前生成，保留已收到内容。SQLite 约每 160ms 接收一次持久化更新；异常退出时最后一小段未保存内容可能丢失。历史入口可选择或删除会话，新建入口创建新会话。界面重开后读取原生状态；不依赖 WebView 页面保持运行。

上下文选择最近最多 16 条完整 user / assistant 消息，按字符预算保守裁剪；空失败回复与相应用户消息一起跳过。它不是精确 tokenizer，系统提示词与当前输入过大仍可能被引擎拒绝。单条正文与思考合计上限为 1 MiB。

## 服务：本机和局域网

加载成功即提供默认 `http://127.0.0.1:8080/v1`。本机地址仅供同一手机上的客户端。打开“允许局域网访问”后服务监听所有网卡，同网设备使用界面显示的手机 IP，不能继续使用自己设备的 `127.0.0.1`。

复制 API 密钥或“连接示例”到客户端。应用每次安装生成随机密钥，模型切换不等于重新生成密钥。局域网采用 HTTP；未提供 TLS、公网穿透和多用户权限管理。详细客户端配置见 [API.md](API.md)。

“运行日志”供排错；导出不包含聊天数据库，并过滤当前 API 密钥。模型服务日志仍可能包含模型文件名和设备运行信息。

## 后台、锁屏和开机恢复

原生 `specialUse` 前台服务、可见通知、CPU 和 Wi-Fi 锁负责维持后台工作。点击“服务”中的电池设置，按系统界面允许豁免；努比亚等厂商系统可能还要允许后台运行、自启动、后台网络及近期任务保护。不同 ROM 菜单不同，不伪造统一操作路径。

退到桌面不会主动结束生成；系统强行停止、低内存、温控、厂商省电和网络断开仍可能中断。当前未做真实锁屏耐久测试。持续输出不是无限生成，一次请求仍在 EOS、token 上限或取消时结束。

通知的“停止服务”停止模型与当前下载；再次打开可继续或加载。可选“开机后恢复服务”默认关闭，只在此前启用且模型文件仍在时尝试恢复；系统禁止时需重新打开应用。应用不自动绕过用户首次下载或系统设置。

## 本地模型设置与应用偏好

在“模型库 → 本地”点击已下载模型的设置图标。上下文、输出、线程、温度、思考和系统提示词均按模型独立保存；数值控件允许选择预设或直接输入。超出 GGUF 上下文约束自动回填最高值；输出最大为所选上下文减一，缩小上下文时也会调整输出。实际输入和历史会进一步占用上下文。未能读取 GGUF 上限时明确标记临时应用上限 8192。完整说明见[模型参数](MODEL_SETTINGS.md)。

修改当前运行模型的上下文、线程或思考模式会重新加载，正在生成时须先停止回复；输出、温度、系统提示词用于下一次应用内对话。修改其他模型不影响当前模型。旧版全局参数自动迁移到已有模型，新模型使用独立默认值。应用设置只保留端口、源、启动及主题等偏好。

| 设置 | 默认 | 影响 |
| --- | --- | --- |
| CPU 线程 | 最多 4 | 更多线程不保证更快，可能更热 |
| 上下文 | 2048 | 增大通常消耗更多内存 |
| 输出上限 | 512 | 应用内回复默认长度；外部客户端自行设定 |
| 温度 | 0.7 | 影响采样随机性 |
| 端口 | 8080 | 1024–65535，需避免占用 |
| 思考 | off | 传给引擎，部分模型可能忽略 |
| 首次自动加载 | 开 | 无已选模型时加载首个下载完成条目 |
| 开机恢复 | 关 | 用户可选，受系统限制 |
| 下载源 | auto | HF 优先，失败后镜像 |
| 主题 | system | 系统 / 浅色 / 深色 |

系统提示词可编辑或留空，没有额外关键词审核。保存得到对应原生成功确认才完成。其他状态更新不会清空未保存的设置或发送失败的草稿。

## 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 不能安装 | 核对 ARM64、Android 9+、下载哈希；已有同包不同签名需先处理签名冲突，卸载会丢失私有数据 |
| 下载失败 / 连接慢 | 尝试固定镜像；检查网络、存储、原始链接；暂停再续传，查看原生错误 |
| SHA256 不符 | 文件不会安装；核对固定版本和来源，删除拒收内容后重下，不跳过校验 |
| 加载失败 / 内存不足 | 使用 `m01`，将上下文降到 1024 / 512，关闭其他大型应用并查看日志 |
| API 连接拒绝 | 确认模型就绪、端口正确、局域网已开启、同网可达且未被 AP 隔离 |
| 401 / 鉴权失败 | 使用当前安装“服务”页密钥，保留 `Authorization: Bearer` 格式 |
| 后台被结束 | 检查通知、电池及厂商后台设置；记录系统版本、供电、模型和发生时间，不保证永久存活 |
| 模型仍拒答 / 思考开关无效 | 确认具体无审查变体、作者说明与提示词；作者声明不等于零拒答，部分模型不响应思考开关 |

卸载会删除模型和聊天。当前未实现模型迁移或聊天备份导入；不要把日志导出误认为完整备份。问题报告请包含版本、手机 / Android、模型 ID 与哈希、参数、复现步骤和去除敏感信息的日志。

Sana 用户可在“全部 / 搜索”选择 `Sana mobile · Qwen3 + MNN`，逐项选择匹配的 13 个 MNN / 权重 / 词表组件，查看计划后单独确认下载；在“本地”管理和编辑该模型的尺寸、CFG、输入 token 与线程。它是移动端匹配变体的文生图配方，不自动支持原版 Sana、图像编辑或 LoRA；无权重捆绑或后台补下载。当前只有编译 / 主机验证，手机效果待实测。见 [Sana 完整说明](MNN_SANA_ENGINE.md)。


开发分支dev.21的SoulX使用入口为已安装模型 → 本机任务：选择连续S1–S4参考音频、逐段填写实际原文，再输入目标说话人文字。单段默认S1，多段每行 `[S1] 原文` 等；模型独立设置在“本地”编辑，任务中覆盖只影响本次。完整14组件、参数 /格式 /API以及公开下载候选仍缺的边界见 [SoulX指南](SOULX_ENGINE.md)。公开v0.2.0没有这一开发能力。
