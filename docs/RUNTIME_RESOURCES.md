# 运行资源保护

[English](RUNTIME_RESOURCES.en.md) · [用户指南](USER_GUIDE.md) · [编号交付 / 完整待办](releases/v0.3.0-dev.31.md)

dev.31 将持续资源检查接入共用执行槽。生成任务、资产准备 / 关联、文本模型加载、聊天及本地 API 使用同一机制。用户仍然自行选择和管理模型；安装、查看资源记录或重试均不自动下载、更新或替换模型文件。

## 使用逻辑

1. 在“本地”选择已安装模型，编辑该模型的参数，完成运行前检查并明确提交任务。
2. 打开“任务”。执行中可见最低系统可用内存、最低可用存储及最高系统温控等级。任务排队期间不记作运行时长。
3. 系统报告严重高温、低内存，或可用存储跌破保留空间时，本次执行停止。生成任务记作失败；未完成文件不发布为成功结果。聊天保留已收到的文本，并显示停止原因。
4. 释放资源后明确选择“重试”，会创建新任务并保留原记录；也可编辑参数后重新生成。文本模型需重新明确加载，资源停止不会触发自动重启。
5. 任务详情保留本次资源摘要；成功结果的来源记录保留同一份已结束摘要。已保存任务在重开应用后仍可查看。

最近停止提示供当前应用进程期间查看；关闭服务后仍可保留，应用进程结束后不再保留。聊天 / API 的执行槽记录和最近停止摘要在内存中，不是持久诊断历史；生成、准备和关联任务的终态摘要写入任务库；运行中不逐次写盘，若系统先终止进程，可能只有中断记录而没有资源摘要。现有模型文件、每模型默认设置和不可变任务请求不因资源保护而修改。

## 检查规则

| 信号 | 停止条件 | 数据来源 / 限制 |
|---|---|---|
| 系统温控 | 等级 ≥ 3（severe） | Android 10+ 公开 PowerManager 接口；这是等级，不是摄氏温度 |
| 系统低内存 | `MemoryInfo.lowMemory=true` | 系统信号；运行中不再次扣除完整模型内存估算，避免重复计算已加载内存 |
| 剩余存储 | 应用所在卷 < 64 MiB | 运行时最低保留空间；不能代替提交 / 执行前的完整输出空间估算 |
| 采样周期 | 执行时约 2 秒一次 | 服务调度、设备忙碌或系统限制可能延迟；不是实时保证 |
| 不可用读数 | 增加不可用次数，不伪造测量值 | Android 9 没有上述温控接口，显示“未知”；不用 ROOT、隐藏 API 或桌面数据补值 |

记录有界：计数、开始 / 结束时间、最小系统可用值、最高温控等级和首次停止原因；不保存无限采样历史。可用 RAM 是整个系统的剩余内存，不能证明模型峰值内存、耗电、速度或后台耐久。

## 共用基座与接口

`DeviceResourceProbe` 只读取公开 Android 状态；`ExecutionGate` 在执行槽拥有者范围内采样并绑定当前原生子进程。读取系统状态在锁外进行，回写前复核槽身份和监测代次。旧采样不能停止后续任务；停止回调和子进程实际退出前不会释放该槽给下一位。

多阶段引擎逐次绑定自己的子进程。发生停止后新启动的阶段会立即被拒绝并回收。停止原因优先于“子进程退出”通用错误。任务库将资源摘要和终态原子保存，校验拥有者令牌；不改写请求。生成完成后冻结观测，再提交结果，避免迟到读数给已发布成功结果增加冲突状态。

文本加载 / 复用进程也绑定到当前槽。严重资源信号先关闭其自动恢复意图，再终止对应子进程。聊天保留部分回复；API 输入流在读取前后检查拥有者，资源中断不会被当成正常 EOF。已开始的 HTTP/SSE 响应可能以连接错误结束，客户端必须检查完成标记，不能把部分内容当完整成功响应。

已鉴权接口 `GET /health` 的 `scheduler`（以及 App `foundation.execution`）包含活动执行槽的 `runtimeResources`、`resourceMonitoringEnabled` 和 `lastResourceStop`。任务详情返回已保存的 `runtimeResources`，成功产物的 `provenance` 包含同名摘要。`scope=shared_system_availability_not_model_peak_memory` 明确测量含义。

空闲常驻模型和排队请求不执行持续采样。服务结束会关闭采样线程。系统强制终止 App、OEM 后台限制或内核直接终止进程可能先于本机制发生；已有任务重启恢复逻辑仍适用，不能据此声称 Android 锁屏验收通过。

## 检查与演示

当前源码的生产队列 / 文本 / HTTP 主机检查包含真实子进程、资源停止、明确重试、部分聊天、接口失败、迟到采样和停止 / 释放竞态。受控系统输入和固定协议输出用于业务回归，**不属于 Android 测量或模型推理验收**。旧 LTX 的真实训练主机链路另行复核，保留原数值失败；不因本功能关闭模型质量或手机门槛。
